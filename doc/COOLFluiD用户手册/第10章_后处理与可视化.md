# 第 10 章 后处理与可视化

本章覆盖求解完成之后的全部分析链路：输出数据格式（10.1）、派生量提取（气动系数/壁面热流/截面数据，10.2）、可视化工作流（ParaView/Tecplot/监控图，10.3）、批处理与对比脚本（10.4）。所有格式均以本仓库实测产物（`burgersFVM.plt`、`convergence.plt.Default`、`P0-output.log`）与 `plugins/`、`tools/` 源码为准。

## 10.1 输出数据格式

### 10.1.1 Tecplot（`TecplotWriter` 插件）

`.plt` 为默认输出格式之一。实测输出头（`burgersFVM.plt`，Burgers 算例 1670 节点/3178 单元）：

```
TITLE = Unstructured grid data
VARIABLES =  "x0" "x1" "u"
ZONE   T= "ZONE0 Triag", N=1670, E=3178, F=FEPOINT, ET=TRIANGLE, SOLUTIONTIME=0.00000000000000e+00
+2.50000000000000e-02 +0.00000000000000e+00 +1.45021554021910e+00
...
```

要点：

- **FEPOINT 非结构格式**，`ET=` 为单元类型（TRIANGLE/QUAD/TETRAHEDRON…）；非定常时每保存时刻一个 ZONE，`SOLUTIONTIME` 标记物理时刻；
- 配置键见 9.3.4：`Simulator.SubSystem.Tecplot.FileName`、`SaveRate`、`AppendTime/AppendIter`、`Data.outputVar`（变量集）、`Data.SurfaceTRS/SurfaceOnly`（面输出）等；
- **并行分块合并**：多进程各写一块（`AppendRank` 或自动分块），用独立命令 `tecplot_merge` 合并：
  ```
  ./install/bin/tecplot_merge <inName> <nbFiles> [initIter maxIter iterStep]
  ```
  前两个参数必填（基准文件名 + 分块数）；非定常多时刻可追加起止迭代与步长（实测 `plugins/TecplotMerge/TecplotMerge.cxx` main）。另有 `tecplot_merge_kopacek`（TecplotMergeKopacek 变体）与 `coef_merge`（系数文件合并，见 10.2.1）；
- Tecplot 接口为**自带的 C 库实现**（`plugins/TecplotWriter/TECXXX.h`、`preutil.c`），不依赖商业 Tecplot 库——输出文件任何 Tecplot 版本都能读。

### 10.1.2 ParaView/VTK（`ParaViewWriter` 插件）

`.vtu/.pvtu` XML 非结构网格格式，ParaView 原生：

```
Simulator.SubSystem.OutputFormat = ParaView
Simulator.SubSystem.ParaView.FileName = sol
Simulator.SubSystem.ParaView.SaveRate = 500
Simulator.SubSystem.ParaView.Data.updateVar = Puvt     # 输出变量集
Simulator.SubSystem.ParaView.Data.SurfaceTRS = Wall    # 可选面输出
```

- 串行写 `.vtu`；并行写 `.pvtu`（分区聚合文件，ParaView 自动加载全部分区）；
- 高阶方法（FR/SD/DG）用 `WriteSolutionHighOrder` 命令输出高阶单元可视化（`plugins/ParaViewWriter/WriteSolutionHighOrder.cxx`）；
- 变量集切换键为 `updateVar`（ParaView 系）/ `outputVar`（Tecplot 系）——两者等价语义，依插件而定（9.3.4 实测）。

### 10.1.3 CGNS（`CGNSWriter` 插件）

`.cgns` 通用 CFD 数据交换格式（需 CGNS 依赖编译）：

```
Simulator.SubSystem.OutputFormat = CGNS
Simulator.SubSystem.CGNS.FileName = sol.cgns
Simulator.SubSystem.CGNS.Data.outputVar = Cons
```

高阶输出用 `CGNSHighOrderWriter`（`FileFormat` 键选择格式）。适合与外部 CFD 工具链（ICEM/CFX/Star 系）交换数据。

### 10.1.4 CFmesh 输出（续算检查点）

```
Simulator.SubSystem.OutputFormat = CFmesh
Simulator.SubSystem.CFmesh.FileName = restart.CFmesh
Simulator.SubSystem.CFmesh.SaveRate = 1000
```

- 写出与 9.4.1 相同的段结构，状态段含当前解向量——是 9.5.5 重启动的唯一输入；
- 并行写出由 `ParCFmeshFileWriter` 完成（日志 `ParCFmeshFileWriter::writeToFile() => IO rank is 0`、`Nodes written/States written`，实测）；
- 也可用 `CellCenterFVM.Restart = true` 续算时把检查点网格改名（9.5.5）。

### 10.1.5 收敛历史文件（`.plt` 变体）

`ConvergenceFile`（默认 `convergence.plt`）实际写为 `convergence.plt.<Namespace>`（`ConvergenceMethod::getFileName` 实测，如 `convergence.plt.Default`），Tecplot 格式 7 列：

```
TITLE  =  Convergence of SubSystem
VARIABLES = Iter Res[0] CFL PhysTime DT WallTime MemUsage
1 -1.55589  0.5 0 -1 0.003345 5.00818e+07
2 -1.56107  0.5 0 -1 0.006525 5.00818e+07
```

| 列 | 含义 |
|----|------|
| Iter | 迭代步数 |
| Res[0] | 残差（log10，第 1 个方程；多方程依次 Res[1]…） |
| CFL | 当前 CFL 数 |
| PhysTime | 物理时间（伪时间推进恒为 0） |
| DT | 时间步长（伪时间推进为 -1） |
| WallTime | 累计墙钟时间（秒） |
| MemUsage | 内存占用（字节） |

`ConvergenceFileOnlyP0 = true` 时仅 rank 0 写（并行默认合并行为，多进程下各 rank 的收敛历史一致）。

## 10.2 派生量提取

### 10.2.1 气动系数（`AeroCoef` 插件）

插件提供按方法族区分的命令与停止条件（`plugins/AeroCoef/`）：

| 命令 | 适用方法 | 说明 |
|------|----------|------|
| `AeroForcesFVMCC` | CellCenter FVM | 壁面积分 Cl/Cd/Cm |
| `AeroForcesFR` / `NavierStokesConsComputeAeroSpectralFD` / `…SpectralFV` / `EulerComputeAeroDG` | FR / SD / SV / DG | 高阶对应版本 |
| `NavierStokesSkinFrictionHeatFluxCC`（2D/3D/NEQ/FR 变体） | FVM | 壁面摩擦系数与热流（10.2.2） |

挂载方式（`DataProcessing`/`DataPostProcessing` 组，第 7.3.1 节 Cylinder 档案实测样例）：

```
Simulator.SubSystem.DataPostProcessing = DataProcessing
Simulator.SubSystem.DataProcessing.Names = AeroCoef1
Simulator.SubSystem.DataProcessing.AeroCoef1.Comds = AeroForcesFVMCC
Simulator.SubSystem.DataProcessing.AeroCoef1.AeroForcesFVMCC.applyTRS = Wall
Simulator.SubSystem.DataProcessing.AeroCoef1.AeroForcesFVMCC.Alpha = "0.0"     # 攻角函数
Simulator.SubSystem.DataProcessing.AeroCoef1.AeroForcesFVMCC.Beta  = "0.0"     # 侧滑角函数
Simulator.SubSystem.DataProcessing.AeroCoef1.AeroForcesFVMCC.OutputFileAero = aeroCoef
Simulator.SubSystem.DataProcessing.AeroCoef1.ProcessRate = 50                  # 每 50 步算一次
```

- 系数以**时间序列文件**输出（`aeroCoef*.plt/.dat`，Cl/Cd/Cm 随迭代变化，第 7.3 节高超声速档案）；
- 并行时各 rank 各写一块，用 `coef_merge` 合并：
  ```
  ./install/bin/coef_merge <inFile> <nbFiles>    # 输出 <inFile>.plt（实测 CoefMerge.cxx main）
  ```
- **收敛判据直接用气动系数**：`StopCondition = AeroCoef` + `ConvCL/ConvCD/ConvCM`（阈值）+ `CheckCL/CheckCD/CheckCM` + `NbIters`（连续 N 步不变才算收敛）+ `MaxIter`（上限）——适合定态气动收敛，替代残差判据（9.3.3）。

### 10.2.2 壁面热流与摩擦

`NavierStokesSkinFrictionHeatFluxCC` 族（2D/3D/NEQ 多温度/FR 高阶版，注册名同名）挂入 DataProcessing 组，`applyTRS = Wall`，输出：

- **壁面摩擦系数** `Cf`（skin friction）；
- **热流** `q` 与 **Stanton 数**（`StantonNumberID` 键选择定义，实测 `NavierStokesSkinFrictionHeatFluxCC.cxx`）；
- NEQ 变体（`…CCNEQ`/`…CCNEQ3D`）额外给出各组分/振动温度通道热流，是高焓算例（第 7.3 节高超声速、7.6 节等离子体档案）的标配后处理。

### 10.2.3 沿线/切面数据

| 工具 | 注册名 | 用途 |
|------|--------|------|
| `Extract2DSectionCC` | 同左 | 提取 2D 截面数据（`plugins/AeroCoef/Extract2DSectionCC.cxx`） |
| `NavierStokesBLExtractionCC` | 同左 | 边界层内沿法向剖面提取（δ、δ*、θ 等，第 7.5.1 节 SA 平板档案实测） |

两者均挂 DataProcessing 组（`ProcessRate` 控制频率）。原大纲拟引用的 `DataHandleOutput`/`ContourIntegrator` 在本版本中**并非面向用户的 `DataProcessing` 后处理命令**：`DataHandleOutput`（继承 `NumericalStrategy`）是 `TecplotWriter` 等 Writer 内部输出实数 DataHandle 的工具类，`ContourIntegrator`（继承 `Integrator<ContourIntegratorImpl>`，配套 `GaussLegendre`/`Trapezium` 等 `IntegratorImplProvider` 实现）是 `ShapeFunctions` 内部线积分器；二者均不注册为 CFcase 可挂的截面/边界层提取命令。截面提取请用 `Extract2DSectionCC`、边界层请用 `NavierStokesBLExtractionCC`。

### 10.2.4 LES 统计量（`LESDataProcessing` 插件）

非定常湍流统计后处理（LES/混合方法算例，第 7.3.1 节 Cylinder 档案的 LES 族）：

| 键 | 示例 | 说明 |
|----|------|------|
| `LESProcessingMethod.ProcessComds` | `ComputeTurbulenceFunctions` | 处理命令表 |
| `LESProcessingData.GradientComputer` | `GradientComputerFVMCC` | 梯度算法（默认） |
| `LESProcessingData.TurbulenceFunctions` / `AverageTurbulenceFunctions` | 函数名表 | 计算/时均的湍流统计量 |
| `ComputeTurbulenceFunctions.ProcessRate` | `1` | 每个时间步都统计 |
| `CFL.DT` | `1e-4` | 计算 CFL 用的时间步 |

输出 Reynolds 应力、湍动能、平均场等（具体量随 TurbulenceFunctions 名），供谱分析/与 DNS 对比。

## 10.3 可视化工作流

### 10.3.1 ParaView 工作流

1. 运行期把 `OutputFormat` 加 `ParaView`（10.1.2）；
2. 打开 `.pvtu`（并行）或 `.vtu`（串行）——并行时 ParaView 自动加载全部 Piece，可逐分区查看负载；
3. 常用操作：等值面（Contour）、流线（Stream Tracer）、Q 判据涡结构（Gradient of Unstructured Dataset → Q）、`SurfaceTRS` 面文件叠加壁面量；
4. 非定常结果用时间播放器（ZONE/SOLUTIONTIME 映射为时间步）。

### 10.3.2 Tecplot 360 与官方宏（`tools/tecplot/` 实测索引）

| 文件 | 用途 |
|------|------|
| `mach.mcr` / `machpt.mcr` / `mach2D.eqn` / `mach3D.eqn` | 马赫数等值线/伪彩宏与方程定义 |
| `poissonWallDistance.eqn` | 壁面距离场可视化 |
| `structDisp2D.eqn` / `structDisp3D.eqn` | 结构位移场（FSI 算例） |
| `writeBinaryFile.mcr` / `writeBinaryAutomatic.sh` | 批量转二进制 Tecplot 文件 |
| `MHD-*` 系列 `.eqn` | MHD 量纲还原/矢量分解（第 7.4 节磁流体档案配套） |
| `convergenceplot.sh` | 收敛曲线脚本（10.3.3） |

用法：Tecplot 360 中 `File → Run Macro` 加载 `.mcr`；`.eqn` 用 `Data → Alter → Specify Equations` 或宏内引用。`writeBinaryAutomatic.sh` 适合大数据集（压缩 ASCII 为二进制，加速后续读取）。

### 10.3.3 残差与目标量监控

- **bash 曲线**：`tools/tecplot/convergenceplot.sh [UPDATETIME=10] [NUMSTEPS=100]`——每 `UPDATETIME` 秒重绘最近 `NUMSTEPS` 步的收敛曲线（生成 PDF）。脚本默认找 `convergence-P0.plt`，运行期可软链接：`ln -sf convergence.plt.Default convergence-P0.plt`；
- **Python 交互监控**：`tools/tecplot/convergence-monitoring.py`——边跑边监视残差，提示按 `CFL*=2` 策略改写 `.inter` 交互参数文件加速收敛（配套 9.3.10 的 `InteractiveParamReader`）；
- **自绘**：收敛文件 7 列格式稳定（10.1.5），一行 `awk`/matplotlib 即可画 `Res[0]` vs `Iter`（10.4.1 模板）。
