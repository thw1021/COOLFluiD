# COOLFluiD 用户手册

# 第 0 章 手册使用说明与阅读指南

本章是整部手册的"地图"。它说明手册的组织方式、不同背景读者的阅读路径、贯穿全书的术语与排版约定，并通过五个典型使用场景给出从"拿到代码"到"完成一次仿真（或一次扩展）"的最短路径。建议所有读者在进入正题之前通读本章——后续各章均遵循本章定义的约定。

## 0.2 术语与排版约定

### 0.2.1 排版约定

| 记法 | 含义 | 示例 |
|------|------|------|
| `等宽字体` | 文件名、目录名、类名、函数名、CFcase 关键字、代码 | `Simulator`、`CellCenterFVM`、`Simulator.Modules.Libs` |
| `代码块` | 命令行、CFcase 片段、源码片段 | 见 0.3 节 |
| *斜体* | 数学量与符号 | *M*∞、*y*⁺ |
| **粗体** | 术语首次出现、强调、警告引导词 | **TRS**（Topological Region Set，拓扑区域集） |
| `> 提示/警告` 引用块 | 使用经验、易错点 | 见 0.3.7 节 |

CFcase（输入文件）中的键值对在正文中以完整键名书写，例如 `Simulator.SubSystem.StopCondition = Norm`；在参数表中则可简写为相对路径（如 `StopCondition`），其完整前缀在参数表表头注明。

### 0.2.2 路径与占位符约定

全书路径除特别说明外，均为**相对 COOLFluiD 源码根目录**的相对路径。使用以下占位符：

| 占位符 | 含义 |
|--------|------|
| `<CF_SRC>` | 源码根目录（本机为 `/home/tang/packages/COOLFluiD`） |
| `<CF_BUILD>` | CMake 构建目录（out-of-source，如 `<CF_SRC>/build/optim`） |
| `<CF_EXE>` | 求解器可执行文件 `<CF_BUILD>/apps/Solver/coolfluid-solver` |

### 0.2.3 关键术语速览

高频术语在此给出一句话定义，完整术语表见第 12.11 节：

- **Kernel（内核）**：`src/` 下的框架代码，不含任何具体物理与数值实现；
- **Plugin（插件）**：`plugins/` 下的动态库（如 `libNavierStokes.so`），实现具体物理模型、数值方法或 IO；运行时由 CFcase 中的 `Simulator.Modules.Libs` 声明加载；
- **CFcase**：COOLFluiD 输入文件，纯文本键值对格式（详见第 9 章），扩展名 `.CFcase`；
- **CFmesh**：COOLFluiD 原生网格/解文件格式（详见第 9.4 节）；
- **TRS**：Topological Region Set，网格上的拓扑区域集（如 `InnerFaces`、`NoSlipWall`），边界条件与初始化命令的作用对象；
- **Provider**：内核工厂机制中的注册项，CFcase 中的方法名字符串（如 `CellCenterFVM`、`NewtonIterator`）经 Provider 定位并实例化对应 C++ 类；
- **VarSet**：变量集（如守恒变量 `Cons`、原始变量 `Puvt`、非平衡变量 `RhoivtTv`），物理模型中各变量体系间的转换封装；
- **FVMCC / RDS / FR / SD / SV / DG**：本手册使用的离散方法缩写——单元中心有限体积（Cell-Centered FVM）、残差分布法（Residual Distribution，即 FluctSplit）、通量重构（Flux Reconstruction）、谱差分（Spectral Difference）、谱体积（Spectral Volume）、间断伽辽金（Discontinuous Galerkin）；
- **LSS**：Linear System Solver，线性系统求解器（PETSc、Pardiso、SAMG 等）；
- **守恒变量（Conservative Variables）**：被求解的未知量向量（如 $(\rho,\rho u,\rho v,\rho E)$），与"原始变量"$(p,u,v,T)$ 相对；见第 3.1.6 节；
- **残差（Residual）** $R$：空间离散后每个控制体上"通量净流出量"，定常解即 $R=0$；代码中为 `socket_rhs`；见第 4.2.1 节；
- **数值通量（Numerical Flux）**：界面两侧状态不同时，用近似 Riemann 求解器给出的唯一界面通量（Roe/AUSM/HLL 等）；见第 4.4 节；
- **重构（Reconstruction）与限制器（Limiter）**：由单元平均值恢复界面左右态的多项式近似，及其抑制间断振荡的非线性因子；见第 4.3 节；
- **CFL 数**：一个时间步内信息传播距离与单元尺度的比值，显式格式要求 CFL<1；见第 4.7.2、4.7.4 节；
- **Jacobian 矩阵** $J=\partial R/\partial U$：隐式方法线化后的系数矩阵，由 `BlockAccumulator` 分块装配；见第 4.8 节；
- **虚拟态（Ghost State）**：边界外侧虚构的单元状态，用于把边界条件统一表达为"普通邻单元"；见第 3.6.5 节。

### 0.2.4 版本与平台基准

- 手册所述行为以 **2013.9 版（Kernel 2.5.0）** 源码为准；涉及上游新版本差异之处会明确标注"自 xxx 版起"。
- 命令行示例默认在 **Linux + Bash** 环境给出；macOS 与 Windows（含 WSL）的差异见第 8 章。
- 串行/并行示例分别使用 `mpirun`（OpenMPI 风格）与本地直接执行两种形式，其他 MPI 实现按第 9.5 节替换。

## 0.3 快速上手路线图

本节给出五个典型场景的最短路径。执行前请确认（首次使用请先阅读第 8 章）：

1. 已完成编译，`<CF_EXE>` 存在且可执行；
2. 插件动态库位于 `<CF_BUILD>/dso/`（动态模式）或已静态链接进可执行文件（`CF_ENABLE_SINGLEEXEC` 模式）；
3. 测试用网格数据已解压（CMake 配置阶段会自动执行 `tools/scripts/init_testcases.sh` 按需解压各插件的 `.xz` 数据包；若构建时跳过，手动执行该脚本即可）。

### 0.3.1 通用运行方法与命令行参数

所有场景的运行方式一致。**建议在源码根目录下运行**，因为多数 CFcase 内的 `Simulator.Paths.WorkingDir` 采用相对源码根目录的路径：

```bash
cd <CF_SRC>
<CF_EXE> --scase plugins/NavierStokes/testcases/Cylinder/cyl_Pg_M15_FVM_1st2nd.CFcase
```

并行运行（网格需预先用 ParMetis 剖分，详见第 9.5.2 节）：

```bash
mpirun -np 4 <CF_EXE> --scase <CFcase 文件>
```

`coolfluid-solver` 命令行参数一览（完整语义见第 9.5.1 节）：

| 参数 | 类型/默认值 | 说明 |
|------|-------------|------|
| `--scase` | 字符串，必填 | CFcase 文件路径（不以 `.`/`/` 开头时，前面拼接 `--bdir` 指定的基目录） |
| `--conf` | 字符串，默认 `coolfluid-solver.xml` | 求解器环境配置文件路径 |
| `--bdir` | 字符串，默认当前目录 | 基目录，CFcase 内相对路径的前缀 |
| `--ldir` | 字符串列表 | 额外的插件库搜索目录（全路径） |
| `--log` | 整数，默认 INFO 级别 | 日志级别（数值越大越详细） |
| `--residual` | 浮点 | 目标残差：运行结束后与 CFcase 元注释 `### Residual` 处方值进行对比校验，超差则退出码为 1（回归测试机制） |
| `--tolerance` | 浮点，默认 3.0 | `--residual` 校验允许的百分比误差 |
| `--wait` / `--waitend` | 布尔开关 | 启动前等待附加调试器 / 结束前暂停 |
| `--testEnv` | 布尔开关 | 仅初始化环境后退出（排查安装/库加载问题的利器） |
| `--help` | 布尔开关 | 打印用法 |

> **注意（本机实测）**：布尔选项必须用**空格分隔传值**，即 `--testEnv 1`、`--help 1`；`--help=1` 等号形式与裸 `--help` 均会报 `BadMatchException`（`no option '--help=1'` / `argument expected for help`，见 8.6.4 节）。日志级别默认 600（INFO），`--log` 数值越大越详细。

程序正常结束返回 0；配置解析失败、插件加载失败或残差校验失败均返回非 0，便于脚本与作业调度系统判断。

### 0.3.2 场景 A：跑通第一个 Euler 算例（FVM 二阶精度）

**目标**：以马赫 15 圆柱绕流（Euler 方程、单元中心 FVM、Roe 通量 + Sanders 熵修正、Venkatakrishnan 限制器、PETSc 隐式 Newton 迭代）为例，完整体验"运行 → 监控 → 出图"流程。

**算例文件**：`plugins/NavierStokes/testcases/Cylinder/cyl_Pg_M15_FVM_1st2nd.CFcase`

**命令**：

```bash
cd <CF_SRC>
<CF_EXE> --scase plugins/NavierStokes/testcases/Cylinder/cyl_Pg_M15_FVM_1st2nd.CFcase
```

**发生了什么**：CFcase 声明加载 9 个插件（`libPetscI libCFmeshFileWriter libCFmeshFileReader libTecplotWriter libNavierStokes libFiniteVolume libNewtonMethod libFiniteVolumeNavierStokes libTecplot2CFmesh`）；网格由 Tecplot 格式自动转换为 CFmesh（`MeshCreator = CFmeshFileReader` + `CFmeshFileReader.convertFrom = Tecplot2CFmesh`）；CFL 采用分段函数爬升（`CFL.ComputeCFL = Function`，`CFL.Function.Def = if(i<300,1.,if(i<345,min(1000.,cfl*1.03^2),...))`）；停止条件为残差达到 `Norm.valueNorm = -9.0`。该算例同时演示了从残差分布法（RDS）一阶解重启 FVM 二阶计算（`CellCenterFVM.Restart = true`）的网格序列策略。

**预期结果**：终端输出各迭代残差；结果写入 `Simulator.Paths.ResultsDir = ./RESULTS_Cylinder_1st2nd` 下的 `.plt`（Tecplot）与 `.CFmesh` 文件（每 500 步保存，`SaveRate = 500`）。CFcase 头部的元注释 `### Residual = -9.1615` 是回归测试的验收值，可用 `--residual -9.1615` 复验。

**进阶阅读**：CFcase 逐行解读见第 9 章；FVM 配置细节见第 4.1、4.2 节；同类算例群见第 7.3 节。

### 0.3.3 场景 B：高超声速热化学非平衡钝体算例（Fire II 再入）

**目标**：运行 Apollo 级再入条件下的 Fire II 双椭球热化学非平衡（TCNEQ，两温度模型）算例，体验非平衡流动求解链。

**算例文件**：`plugins/NEQ/testcases/TCNEQ/FireII/`（`fire2_1643s_TCNEQ.CFcase` 及其 CNEQ、Mutation++ 变体 `fire2_1643s_CNEQ.CFcase`、`fire2_1643s_CNEQ_M++.CFcase`）

**命令**：

```bash
cd <CF_SRC>
<CF_EXE> --scase plugins/NEQ/testcases/TCNEQ/FireII/fire2_1643s_TCNEQ.CFcase
```

**发生了什么**：该 CFcase 加载物理模型插件 `libNEQ`、求解插件 `libFiniteVolumeNEQ`，并通过 `libMutation2OLD`/`libMutation2OLDI` 接入 Mutation 2 物理化学库（air-11 组分、Park 1993 空气反应模型，含振动-化学耦合源项）；网格由 Gambit `.neu` 经 `libGambit2CFmesh` 转入（同时加载了 `libGmsh2CFmesh` 备用）；`libAeroCoefFVM`/`libAeroCoefFVMNEQ` 在运行中输出壁面气动与热流系数。

**预期结果**：含组分质量分数、振动温度等附加变量的流场输出；壁面热流分布可用于与 Fire II 飞行试验数据对标（参考数据与文献见第 7.2 节）。

> **警告**：非平衡算例对初始条件与 CFL 策略敏感。若发散，请先用同目录下的 CNEQ（化学非平衡单温度）算例起步，再切换 TCNEQ；CFL 爬升函数的写法见第 9.3.6 节。

**进阶阅读**：热化学非平衡物理见第 3.2.5 节；NEQ 插件详解见第 6.2.2 节；高焓算例群与对标数据见第 7.2 节。

### 0.3.4 场景 C：MHD 多流体算例（Brio–Wu 磁激波管）

**目标**：运行多流体磁流体动力学（MultiFluid MHD）的经典基准——Brio–Wu 激波管，验证 MHD 求解链。

**算例文件**：`plugins/MultiFluidMHD/testcases/11_BrioWuTube/`（`1_BrioWu.CFcase` + 交互参数文件 `BrioWu.inter` + Gambit 网格 `shockTube_1x6e-3_600x4.neu`）

**命令**：

```bash
cd <CF_SRC>
<CF_EXE> --scase plugins/MultiFluidMHD/testcases/11_BrioWuTube/1_BrioWu.CFcase
```

**发生了什么**：加载 `libMultiFluidMHD`、`libFiniteVolumeMultiFluidMHD`（以及 `libMaxwell`/`libFiniteVolumeMaxwell` 电磁插件族）；时间推进**实际启用的是 `ConvergenceMethod = BDF2`**（`1_BrioWu.CFcase:146`；文件头部的 `FwdEuler` 与 `NewtonIterator` 两行均被注释掉）。⚠️ 旧版写"显式时间推进 `libForwardEuler`"——`libForwardEuler` 确实在 `Modules.Libs` 中被加载，但**并未启用**，该算例走的是 BDF2 隐式路线。该算例族还使用 `.inter` 交互参数文件（`Simulator.SubSystem.InteractiveParamReader.FileName = plugins/MultiFluidMHD/testcases/11_BrioWuTube/BrioWu.inter`）承载随算例变化的初值参数；网格为 Gambit `.neu` 格式（`convertFrom = Gambit2CFmesh`）。

**预期结果**：一维磁激波管七波系结构；可用同目录其他算例（Hartmann 流 `1_HartmannFlow`、磁重联 `2_MagneticReconnection`、Orszag-Tang `6_OrszagTang` 等）进一步验证（见第 7.4 节）。

**进阶阅读**：MHD 方程与投影变量集见第 3.2.4 节；多流体 MHD 插件见第 6.2.4 节。

### 0.3.5 场景 D：高阶方法算例（通量重构 FR 与谱差分 SD）

**目标**：分别用通量重构（FR/CPR）与谱差分（SD）方法求解圆柱 Euler 绕流，体验高阶精度配置。

**算例文件**：

- FR：`plugins/NavierStokes/testcases/Cylinder/cylinderEuler2DFR-impl.CFcase`（隐式 BackwardEuler + PETSc；同目录另有 P4–P8 阶次收敛族 `cylinderEuler2DFR-impl_P4.CFcase` … `_P8.CFcase`）；
- SD：`plugins/NavierStokes/testcases/AccPulse/accpulse2d-sfdm.CFcase`（低存储 Runge–Kutta `RungeKuttaLS` 推进；同目录含 P1–P5 收敛族与并行/双时间步变体）。

**命令**（以 FR 为例）：

```bash
cd <CF_SRC>
<CF_EXE> --scase plugins/NavierStokes/testcases/Cylinder/cylinderEuler2DFR-impl.CFcase
```

**发生了什么**：FR 算例加载 `libFluxReconstructionMethod` 与物理扩展 `libFluxReconstructionNavierStokes`，输出经 `libParaViewWriter` 写为 VTK（ParaView 直接可读）；SD 算例加载 `libSpectralFD` 与 `libRungeKuttaLS`，网格由 THOR 格式经 `libTHOR2CFmesh` 转入（`CFmeshFileReader.convertFrom = THOR2CFmesh`，`SolutionOrder = P0`、`Discontinuous = true`）。

**预期结果**：对比 P1–P8（FR）或 P1–P5（SD）各阶次的升力/阻力或声压误差，可绘制收敛阶曲线（方法见第 7.8 节）。

**进阶阅读**：FR 原理与配置见第 4.10 节；SD/SV 见第 4.11.1–4.11.3 节；上游《FluxReconstructionManual.pdf》见 0.4 节。

### 0.3.6 场景 E：增加一个自定义插件（开发者路径）

**目标**：以内核自带的骨架插件为模板，建立你的第一个可编译、可被 CFcase 调用的插件。

**最短路径**（详细步骤化教程见第 11.3 节）：

1. 阅读骨架插件 `plugins/EmptySpaceMethod/`（共 16 个文件）：`EmptySolver(.hh/.cxx)` 定义 SpaceMethod 主体，`StdSetup/StdSolve/StdUnSetup(.hh/.cxx)` 是命令三件套，`EmptyStrategy` 演示策略 Provider，`EmptyMeshDataBuilder` 演示网格构建器，`CMakeLists.txt` 展示插件编译的最小配置；
2. 复制该目录为 `plugins/MyPlugin`，全局替换命名；
3. 在 `plugins/CMakeLists.txt` 的自动扫描机制下（遍历所有 `*/CMakeLists.txt`）重新执行 CMake 即可纳入构建；
4. 在 CFcase 的 `Simulator.Modules.Libs` 中加入 `libMyPlugin`，并将 `Simulator.SubSystem.SpaceMethod` 指向你的方法名。

> **提示**：源码树外的插件开发（不打乱上游目录）可使用 CMake 选项 `CF_EXTRA_SEARCH_DIRS` 指定额外插件搜索路径，见第 8.2.1 节与第 11.3.1 节。

**进阶阅读**：Provider/工厂机制原理见第 2.7 节；新增物理模型与数值格式的完整教程见第 11.4、11.5 节。

### 0.3.7 快速上手常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `Could not load library libXxx` | 插件库不在搜索路径，或未编译该插件 | 确认 `<CF_BUILD>/dso/` 下存在对应 `.so`；必要时用 `--ldir` 显式指定；插件是否随构建启用见第 6.3.4 节 |
| 网格/结果文件找不到 | 在错误目录运行（CFcase 内 `WorkingDir` 为相对路径） | 回到源码根目录运行，或用 `--bdir` 指定基目录（见 0.3.1 节） |
| 结果目录写入失败 | `ResultsDir` 指向的目录不存在或无写权限 | 预先创建目录，或修改 CFcase 中 `Simulator.Paths.ResultsDir` |
| 启动即报未识别参数 | CFcase 出现拼写错误或插件未加载（其专属选项无法归属） | 核对键名（注意大小写）；先运行 `--testEnv 1` 验证插件加载链 |
| 残差不收敛/发散 | CFL 过大、初值不当、格式与马赫数不匹配 | 用低 CFL 起步并配置爬升函数；参考同类算例的 `CFL.Function.Def`（0.3.2 节） |
| 想确认环境是否正常 | — | `<CF_EXE> --scase <任意CFcase> --testEnv 1` 仅初始化环境后退出 |

更完整的运行期故障排查表见第 12.9 节。
