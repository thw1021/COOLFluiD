## 3.1 预备知识：流体力学的基本概念与符号

### 3.1.1 连续介质假设与两种描述方式

**连续介质假设**：本章所有方程都建立在"流体是连续充满空间的介质"之上——即在任意小的体积内，密度、速度、温度等都有确定的值。其成立条件是分子平均自由程 $\lambda$ 远小于流动特征尺度 $L$，即克努森数

$$Kn = \frac{\lambda}{L} \ll 0.01$$

**这条假设就是 COOLFluiD 的适用边界**：高超声速再入的稀薄高层大气区（$Kn>0.1$）已超出 N-S 方程适用范围，需 DSCM/PIC 类粒子方法；COOLFluiD 的高焓能力（NEQ 模型，3.2.5 节）覆盖的是**连续流区内的热化学非平衡**，而不是稀薄流本身。判断依据见第 7.3 节算例的高度/密度参数。

**两种描述方式**：

| 方式 | 含义 | 是否用于本书 |
|------|------|--------------|
| 拉格朗日（Lagrange） | 跟随流体微团，记录其轨迹与状态变化 | 仅用于粒子类方法 |
| **欧拉（Euler）** | 站在空间固定点，观察流经此处的流体状态 | **本书全部方法** |

欧拉描述下，流场是坐标与时间的函数：$\rho(\mathbf{x},t)$、$\mathbf{u}(\mathbf{x},t)$、$p(\mathbf{x},t)$……

**物质导数（随体导数）**：流体微团的物理量变化率 = 当地变化 + 对流输运：

$$\frac{D\phi}{Dt} = \frac{\partial \phi}{\partial t} + \underbrace{(\mathbf{u}\cdot\nabla)\phi}_{\text{对流项}}$$

其中对流项 $(\mathbf{u}\cdot\nabla)\phi$ 是**非线性**的（$\mathbf{u}$ 本身是未知量），这正是 CFD 必须用迭代求解、且强对流问题难收敛的根源。代码中人们常说"对流项（convective term）"即指与此相关的部分。

### 3.1.3 守恒律的通用形式

所有本章的流体方程都可以写成同一个"守恒律"模板。理解这个模板，就理解了全书 90% 的方程：

**微分形式**（要求解光滑）：

$$\frac{\partial U}{\partial t} + \nabla\cdot\mathbf{F}(U) = \nabla\cdot\mathbf{F}_v(U,\nabla U) + S(U)$$

**积分形式**（允许解含间断，**这是有限体积法的出发点**）：

$$\frac{d}{dt}\int_{\Omega} U\,dV + \oint_{\partial\Omega} \mathbf{F}(U)\cdot\mathbf{n}\,dS = \oint_{\partial\Omega} \mathbf{F}_v\cdot\mathbf{n}\,dS + \int_{\Omega} S\,dV$$

| 符号 | 名称 | 含义 |
|------|------|------|
| $U$ | 守恒变量向量（conservative variables） | 被求解的未知量，如 $(\rho,\rho u,\rho v,\rho E)^T$ |
| $\mathbf{F}(U)$ | 对流通量（convective/inviscid flux） | 由流体整体运动携带的输运，双曲型 |
| $\mathbf{F}_v$ | 粘性/扩散通量（viscous/diffusive flux） | 由粘性、热传导引起的输运，抛物型 |
| $S(U)$ | 源项（source term） | 化学反应、辐射、电磁力、轴对称几何源项等 |
| $\Omega,\partial\Omega$ | 控制体及其边界 | 网格单元与单元面 |
| $\mathbf{n}$ | 外法向单位矢量 | 代码中 `getMethodData().getUnitNormal()` |

**为什么必须用守恒形式？** 只有守恒形式才能保证激波位置和激波强度正确（满足 Rankine–Hugoniot 关系）。若用非守恒形式（如原始变量 $\partial p/\partial t+\mathbf{u}\cdot\nabla p+\dots$），激波速度会算错。COOLFluiD 的 FVM/RDS/FR 全部基于守恒形式；**变量集可以换（$Puvt$/$Cons$/$Roe$），但底层积分的始终是守恒通量**——变量集的作用只是"用哪组变量做重构和线化"，见 3.1.6 与 4.2.3 节。

### 3.1.4 本构关系与封闭：让方程可解

Euler 方程 + 完全气体状态方程即可封闭；N-S 方程还需要粘性应力与热传导的本构关系。

**(1) 完全气体状态方程（Equation of State, EOS）**

$$p = \rho R T = (\gamma-1)\rho e$$

其中 $e=c_v T$，$c_v = R/(\gamma-1)$。总能量形式：

$$p = (\gamma-1)\rho\left(E - \tfrac{1}{2}V^2\right) \quad\Longleftrightarrow\quad p = (\gamma-1)\left(\rho E - \tfrac{1}{2}\rho V^2\right)$$

**源码对照**（`plugins/NavierStokes/Euler2DCons.cxx:441-465`，守恒变量集由状态向量反算物理量）：

```cpp
void Euler2DCons::computePhysicalData(const State& state, RealVector& data)
{
  const CFreal rho   = state[0];              // ρ  = U[0]
  const CFreal ovRho = 1./rho;
  const CFreal u     = state[1]*ovRho;        // u  = (ρu)/ρ
  const CFreal v     = state[2]*ovRho;        // v  = (ρv)/ρ
  const CFreal V2    = u*u + v*v;             // V²
  const CFreal gamma = getModel()->getGamma();
  const CFreal gammaMinus1 = gamma - 1.;

  data[EulerTerm::RHO] = rho;
  data[EulerTerm::P]   = gammaMinus1*(state[3] - 0.5*rho*V2);  // p=(γ-1)(ρE-½ρV²)

  const CFreal pOvRho = data[EulerTerm::P]*ovRho;
  data[EulerTerm::E]  = state[3]*ovRho;                 // E = ρE/ρ
  data[EulerTerm::H]  = data[EulerTerm::E] + pOvRho;    // H = E + p/ρ
  data[EulerTerm::A]  = sqrt(gamma*pOvRho);             // a = √(γp/ρ)
  data[EulerTerm::T]  = pOvRho/getModel()->getR();      // T = p/(ρR)
  data[EulerTerm::V]  = sqrt(V2);
  data[EulerTerm::VX] = u;
  data[EulerTerm::VY] = v;
  data[EulerTerm::GAMMA] = gamma;
}
```

**逐行变量对照表**：

| 代码变量 | 数学符号 | 物理含义 |
|----------|----------|----------|
| `state[0..3]` | $U_0..U_3$ | 守恒变量 $(\rho,\rho u,\rho v,\rho E)$ |
| `ovRho` | $1/\rho$ | 密度倒数（避免除法、加速） |
| `V2` | $V^2=u^2+v^2$ | 速度平方 |
| `gammaMinus1` | $\gamma-1$ | 比热比减一 |
| `pOvRho` | $p/\rho$ | 比压（= $RT$） |
| `data[EulerTerm::H]` | $H$ | 总焓，用于能量通量 $\rho u_n H$ |

> **初学者提示**："从守恒量反算压力和温度"这一步叫 **解码（decode）**，是每步残差计算都要做的；反过来"从 $p,u,v,T$ 组装守恒量"叫 **编码（encode）**，对应 `computeStateFromPhysicalData()`（同文件 469 行起）。两者互逆，构成了不同变量集之间转换的基础。

**(2) 牛顿流体本构 + Stokes 假设**

$$\tau_{ij} = \mu\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i} - \frac{2}{3}\frac{\partial u_k}{\partial x_k}\delta_{ij}\right)$$

第二项 $-\tfrac23\mu\nabla\cdot\mathbf{u}$ 是体积粘性项，来自 **Stokes 假设**（体积粘性系数 $\lambda = -2\mu/3$，对单原子气体严格成立，对空气是很好的近似）。

**(3) 傅里叶热传导定律**

$$\mathbf{q} = -k\nabla T$$

负号表示热量从高温流向低温。工程中常用普朗特数把 $k$ 与 $\mu$ 联系起来：

$$Pr = \frac{\mu c_p}{k} \quad\Rightarrow\quad k = \frac{\mu c_p}{Pr},\qquad c_p = \frac{\gamma R}{\gamma-1}$$

空气 $Pr\approx0.72$——这意味着**只要给定了 $\mu$ 的规律，$k$ 就自动确定**，这也是 CFcase 里只配粘性规律（`Reynolds` 或 Sutherland）而不配 $k$ 的原因。

**(4) 粘性系数规律**

| 规律 | 公式 | 代码/配置 |
|------|------|-----------|
| 常数 | $\mu=\mathrm{const}$ | `ConstantDynViscosity` |
| Sutherland | $\displaystyle \mu = \mu_{ref}\left(\frac{T}{T_{ref}}\right)^{3/2}\frac{T_{ref}+S}{T+S}$ | `DynamicViscosityLaw`（$S\approx110.4\,$K，空气） |
| 无量纲给定 | $\mu = \rho_\infty V_\infty L/Re$ | CFcase `DiffTerm.Reynolds`（3.7 节） |

### 3.1.5 无量纲化：参考量与无量纲数

有量纲方程里参数众多（$\rho_\infty,p_\infty,\mu,L\dots$），无量纲化后只剩几个**无量纲数**，便于比较与调参。取参考量 $\rho_\infty,V_\infty,T_\infty,L$：

$$x^* = \frac{x}{L},\quad t^* = \frac{tV_\infty}{L},\quad \rho^* = \frac{\rho}{\rho_\infty},\quad p^* = \frac{p}{\rho_\infty V_\infty^2},\quad T^* = \frac{T}{T_\infty}$$

代入 N-S 方程后出现的无量纲数：

| 数 | 定义 | 物理含义 |
|----|------|----------|
| 雷诺数 $Re$ | $\rho_\infty V_\infty L/\mu_\infty$ | 惯性力/粘性力；越大边界层越薄、越易转捩 |
| 马赫数 $M$ | $V_\infty/a_\infty$ | 流速/声速；$>0.3$ 须考虑压缩性，$>1$ 出现激波 |
| 普朗特数 $Pr$ | $\mu c_p/k$ | 动量扩散/热扩散之比 |
| 克努森数 $Kn$ | $\lambda/L$ | 连续介质假设的判据（3.1.1） |

无量纲 N-S 方程（以 $Re$ 为系数出现在粘性项）：

$$\frac{\partial U^*}{\partial t^*} + \nabla^*\cdot\mathbf{F}^* = \frac{1}{Re}\nabla^*\cdot\mathbf{F}_v^* + S^*$$

**这就是 CFcase 中 `DiffTerm.Reynolds` 的来源**：无量纲模式下，粘性项的 $1/Re$ 由用户直接给出（如 `doubleEllipseNS_PG.CFcase` 的 `DiffTerm.Reynolds = 17212.3847`）。有量纲模式则给真实参考态（`refValues`）+ 粘性规律，代码自行换算。详见 3.7 节。

### 3.1.6 变量集：同一个方程，不同的"存放方式"

这是 COOLFluiD 初学者最容易困惑的概念。**方程是同一套方程，但状态向量里可以存不同的量**：

| 变量集 | 状态向量内容 | 为什么用它 |
|--------|--------------|-----------|
| `Cons`（$Cons$） | $(\rho,\rho u,\rho v,\rho E)$ | 守恒性好，激波位置准确；但重构可能产生负密度/负压力 |
| `Puvt` | $(p,u,v,T)$ | 原始变量，**重构时易保证物理性**（压力/密度恒正），收敛更稳 |
| `Roe` | Roe 平均变量 $(\sqrt\rho,\sqrt\rho u,\dots)$ | 线化（Jacobian）时数值性质好 |
| `Char` | 特征变量 | 按波系分解，边界条件易施加 |
| `Symm` | 对称变量 | Jacobian 对称，某些格式稳定 |
| `RhoivtTv`（NEQ） | $(\rho_i,\mathbf{v},T,T_{v,k},T_e)$ | 非平衡流必须携带组分与多温度自由度 |

**代码中的四个"变量槽位"**（CFcase `Simulator.SubSystem.<方法>.Data.<槽位>`，见第 9 章）：

| 槽位 | 作用 | 典型取值 |
|------|------|----------|
| `UpdateVar` | **求解与更新的变量**（未知量本身） | `Cons` / `Puvt` |
| `SolutionVar` | 通量计算所用的变量 | `Cons` |
| `LinearVar` | 线化（Jacobian）所用的变量 | `Roe` / `RoeVinokur` |
| `DiffusiveVar` | 粘性项计算所用的变量 | `Puvt`（因为需要梯度本身） |

变量集之间的转换由 `VarSetTransformer` 家族实现（`getUpdateToSolutionVecTrans()` 等，见 4.4.3 节），全部**解析实现**（有精确 Jacobian），不是数值近似。

## 3.2 控制方程逐个推导

### 3.2.1 可压缩 Euler 方程（无粘流动）

**物理假设**：无粘（$\mu=0$）、无热传导（$k=0$）、无体力和源项。适用于高雷诺数流动的**激波/膨胀波主导区域**（如高超声速钝体绕流的激波层外部）。

**守恒形式（2D）**：

$$\frac{\partial U}{\partial t} + \frac{\partial F_x}{\partial x} + \frac{\partial F_y}{\partial y} = 0$$

$$U = \begin{pmatrix} \rho \\ \rho u \\ \rho v \\ \rho E \end{pmatrix},\quad
F_x = \begin{pmatrix} \rho u \\ \rho u^2 + p \\ \rho u v \\ \rho u H \end{pmatrix},\quad
F_y = \begin{pmatrix} \rho v \\ \rho u v \\ \rho v^2 + p \\ \rho v H \end{pmatrix}$$

**逐项物理解释**（以 $F_x$ 为例）：

| 分量 | 表达式 | 物理含义 |
|------|--------|----------|
| 第 1 行 $\rho u$ | 质量通量 | 单位时间通过单位面积的质量 |
| 第 2 行 $\rho u^2+p$ | 动量通量 | $\rho u^2$ = 对流携带的 $x$ 动量 + $p$ = 压力对微团的推力 |
| 第 3 行 $\rho uv$ | $y$ 动量通量 | 由 $x$ 方向流动携带的 $y$ 方向动量 |
| 第 4 行 $\rho uH$ | 能量通量 | 总焓（内能+动能+流动功）随质量的携带 |

**封闭**：$p=(\gamma-1)\left(\rho E-\tfrac12\rho V^2\right)$（3.1.4 节）。4 个方程、4 个未知量（$U$ 的 4 个分量），封闭。

### 3.2.2 Navier-Stokes 方程（粘性流动）

**物理假设**：牛顿流体（3.1.4）+ 傅里叶热传导 + 连续介质。相比 Euler 增加了**粘性应力**（动量扩散）与**热传导**（能量扩散）。

**守恒形式（2D，分量展开）**：

$$\frac{\partial}{\partial t}\begin{pmatrix} \rho \\ \rho u \\ \rho v \\ \rho E \end{pmatrix}
+ \frac{\partial}{\partial x}\begin{pmatrix} \rho u \\ \rho u^2+p \\ \rho uv \\ \rho uH \end{pmatrix}
+ \frac{\partial}{\partial y}\begin{pmatrix} \rho v \\ \rho uv \\ \rho v^2+p \\ \rho vH \end{pmatrix}
= \frac{\partial}{\partial x}\begin{pmatrix} 0 \\ \tau_{xx} \\ \tau_{xy} \\ u\tau_{xx}+v\tau_{xy}-q_x \end{pmatrix}
+ \frac{\partial}{\partial y}\begin{pmatrix} 0 \\ \tau_{xy} \\ \tau_{yy} \\ u\tau_{xy}+v\tau_{yy}-q_y \end{pmatrix}$$

粘性应力与热流（2D 展开，$\nabla\cdot\mathbf{u}=\partial_x u+\partial_y v$）：

$$\tau_{xx} = 2\mu\frac{\partial u}{\partial x} - \frac{2}{3}\mu\left(\frac{\partial u}{\partial x}+\frac{\partial v}{\partial y}\right),\quad
\tau_{yy} = 2\mu\frac{\partial v}{\partial y} - \frac{2}{3}\mu\left(\frac{\partial u}{\partial x}+\frac{\partial v}{\partial y}\right),\quad
\tau_{xy} = \mu\left(\frac{\partial u}{\partial y}+\frac{\partial v}{\partial x}\right)$$

$$q_x = -k\frac{\partial T}{\partial x},\qquad q_y = -k\frac{\partial T}{\partial y}$$

**能量方程最后两项的物理含义**：$u\tau_{xx}+v\tau_{xy}$ 是**粘性做功**（摩擦生热，高超声速下使壁面温度急剧升高——这正是气动加热的来源）；$-q_x$ 是热传导损失。

**数学性质变化**：Euler 方程是纯**双曲型**（信息以有限速度沿特征线传播）；N-S 方程因粘性项是**双曲-抛物混合型**（粘性使信息"瞬时扩散"，且带来刚性）。这直接影响算法：粘性项需要**梯度**（4.5 节），且显式格式的时间步受粘性稳定性限制 $\Delta t \propto \Delta x^2/\nu$（比对流限制严苛得多）。

**源码对照**：粘性通量的计算在 `plugins/FiniteVolume/NSFlux.ci:59-140`（模板类 `NSFlux<DIFFVS>`，注册名 `"NavierStokes"`）：

### 3.2.3 雷诺平均（RANS）与湍流模型

**物理背景**：湍流包含极宽的尺度范围。直接模拟（DNS）需要网格分辨到最小涡（Kolmogorov 尺度），网格量 $\sim Re^{9/4}$，工程上不可行。

**雷诺平均的推导**：把瞬时量分解为平均 + 脉动（$u_i = \bar u_i + u_i'$），代入 N-S 方程并平均，得到 RANS 方程。**关键后果**是对流项的非线性产生了新的未知量——**雷诺应力**：

$$-\rho\overline{u_i' u_j'} \quad（6\ 个独立分量）$$

这就是**湍流封闭问题**。COOLFluiD 用 **Boussinesq 涡粘假设**封闭：

$$-\rho\overline{u_i'u_j'} = \mu_t\left(\frac{\partial \bar u_i}{\partial x_j}+\frac{\partial \bar u_j}{\partial x_i}\right) - \frac{2}{3}\rho k\,\delta_{ij}$$

把封闭问题转化为"求湍流粘度 $\mu_t$"。

**(1) Spalart–Allmaras（一方程，`SA` 插件）**

求解工作变量 $\tilde\nu$：

$$\frac{\partial \tilde\nu}{\partial t} + u_j\frac{\partial\tilde\nu}{\partial x_j}
= \underbrace{c_{b1}\tilde S\tilde\nu}_{\text{产生}} - \underbrace{\left[c_{w1}f_w\right]\left(\frac{\tilde\nu}{d}\right)^2}_{\text{破坏}}
+ \frac{1}{\sigma}\left[\nabla\cdot\left((\nu+\tilde\nu)\nabla\tilde\nu\right) + c_{b2}|\nabla\tilde\nu|^2\right]$$

其中 $d$ 是到最近壁面的距离（代码中 `setWallDistance()` / `WallCutOffDistance` 相关命令），$\tilde S$ 含旋转率修正。湍流粘度 $\mu_t = \rho\tilde\nu f_{v1}$，$f_{v1}=\chi^3/(\chi^3+c_{v1}^3)$，$\chi=\tilde\nu/\nu$。

**为什么 SA 在航空航天外流中流行？** 单方程、对附着边界层与弱分离精度好、鲁棒、对网格质量要求相对低。

**(2) $k$-$\omega$ SST / $k$-$\log\omega$（两方程，`KOmega` 插件）**

$$\frac{\partial (\rho k)}{\partial t}+\nabla\cdot(\rho k\mathbf{u}) = \underbrace{P_k}_{\text{湍动能产生}} - \beta^*\rho k\omega + \nabla\cdot\left[(\mu+\sigma_k\mu_t)\nabla k\right]$$

$$\frac{\partial (\rho\omega)}{\partial t}+\nabla\cdot(\rho\omega\mathbf{u}) = \frac{\gamma}{\nu_t}P_k - \beta\rho\omega^2 + \nabla\cdot\left[(\mu+\sigma_\omega\mu_t)\nabla\omega\right] + \underbrace{2(1-F_1)\frac{\rho\sigma_{\omega 2}}{\omega}\nabla k\cdot\nabla\omega}_{\text{交叉扩散项}}$$

$\mu_t = \rho k/\omega$。代码提供 $k$-$\omega$ 与 **$k$-$\log\omega$** 两种形式：后者求解 $\ln\omega$，**保证 $\omega$ 恒正**，数值上更鲁棒。

**(3) $\gamma$-$Re_\theta$ 转捩模型（`GReKO`、`GammaAlpha` 插件）**

在 $k$-$\omega$ 基础上增加间歇因子 $\gamma$ 与转捩雷诺数 $\widetilde{Re}_{\theta t}$ 两个方程，预测层流→湍流的转捩位置。用于 T3A 平板等转捩验证算例（第 7.5.2 节）。

**(4) LES 亚格子模型（`LES`/`LESvki` 插件）**

大涡模拟只模拟大尺度涡，小尺度用亚格子模型：Smagorinsky（$\mu_{SGS}=\rho(C_s\Delta)^2|\bar S|$）、**WALE**（壁面自适应，近壁 $\mu_{SGS}\to0$，无需阻尼函数）、Clark（梯度型）。注册名 `LES2D/3D`、`Smagorinsky2D/3D`、`WALES2D/3D`、`Clark2D`、`Gradient2D`。

**湍流模型的注册方式**：以"物理模型 + 湍流扩展"组合注册（均在 `PhysicalModelImpl` 工厂）：

| 模型注册名 | 模型 | 插件 |

| `NavierStokes2DKOmega` / `NavierStokes3DKOmega` | $k$-$\omega$ | `KOmega` |

**关键洞察**：`Omega = exp(...)` 就是 $k$-$\log\omega$ 的全部秘密——**求解变量不是 $\omega$ 而是 $\ln\omega$**，因此 $\omega=e^{\ln\omega}>0$ 恒成立，从构造上杜绝了 $\omega\le0$ 导致的除零与发散。这解释了为什么 `KLogOmega` 变体在复杂外形上更鲁棒。

**SST 变体**（`plugins/KOmega/NavierStokesKOmegaSSTVarSet.ci:52-79`）：

> **与 $k$-$\log\omega$ 的两个差别（读代码时务必注意）**：
> 1. SST 里 `const CFreal Omega = state[this->_kID+1];`（:53）**没有 `exp`**——SST 变体直接存 $\omega$；只有 `KLogOmega`（及 `…LogOmegaSST`）才存 $\ln\omega$ 并 `Omega = exp(state[...])`（`NavierStokesKLogOmegaVarSet.ci:84`）。
> 2. SST 的 `const CFreal K = state[this->_kID];`（:52）**没有** `std::max(0., …)` 限幅；而 `KLogOmega` 版本是 `std::max(0., state[this->_kID])`（:83）。两者对 $k<0$ 的鲁棒性不同。
> 3. 整段被 `if ((this->_wallDistance > 0.) && (gradients.size() > 0))`（:47）包裹——**未计算壁面距离时 `mut` 恒为 0**（即退化为层流），这是"配了 SST 却完全没湍流粘性"的头号原因。

对应 Menter SST 的**湍流粘度限制器**：

$$\mu_t = \frac{\rho\,a_1 k}{\max\left(a_1\omega,\ \lvert\Omega\rvert F_2\right)},\qquad a_1 = 0.31$$

它等价于 $\mu_t=\rho k/\omega$ 与 $\mu_t = \rho a_1 k/(\lvert\Omega\rvert F_2)$ 取小——**SST 通过抑制分离区过高的湍流粘度，显著改善逆压梯度分离的预测**（这正是 SST 优于标准 $k$-$\omega$ 的原因）。

```cpp
const CFreal nuSGS = pow(Cs,2)*pow(D,2)*S;               // ν_SGS = (C_s Δ)²|S̄|
```

### 3.2.4 磁流体力学（MHD）方程

**物理背景**：导电流体（等离子体）在磁场中运动，流体与电磁场双向耦合：流体运动感应出电流、改变磁场；磁场通过洛伦兹力 $\mathbf{J}\times\mathbf{B}$ 反过来作用于流体。

**理想 MHD 方程**（8 个守恒量，3D）：

$$\frac{\partial}{\partial t}\begin{pmatrix} \rho \\ \rho\mathbf{u} \\ \mathbf{B} \\ \rho E \end{pmatrix}
+ \nabla\cdot\begin{pmatrix}
\rho\mathbf{u} \\
\rho\mathbf{u}\mathbf{u} + \left(p+\tfrac{B^2}{2}\right)\mathbf{I} - \mathbf{B}\mathbf{B} \\
\mathbf{u}\mathbf{B} - \mathbf{B}\mathbf{u} \\
\left(\rho E + p + \tfrac{B^2}{2}\right)\mathbf{u} - \mathbf{B}(\mathbf{u}\cdot\mathbf{B})
\end{pmatrix} = 0$$

其中总能量含磁能：$\rho E = \rho e + \tfrac12\rho V^2 + \tfrac{B^2}{2}$（$B^2/2$ 为磁压，$\mathbf{B}\mathbf{B}$ 项为**磁张力**——磁力线像橡皮筋一样有沿自身方向的张力）。

**方程个数（务必按模型区分）**：上式的"8 个守恒量"只对**理想 MHD** 成立（源码 `plugins/MHD/MHDPhysicalModel.ci:47-50` 中 `getNbEquations()` 直接 `return 8;`，`MHD3DCons.cxx:42-54` 的分量名依次为 `rho, rhoU, rhoV, rhoW, Bx, By, Bz, rhoE`）。各投影（GLM）变体因为多了解耦/耗散变量，方程数不同：

| 模型注册名 | $n_{eq}$ | 源码 |
|---|---|---|
| `MHD2D` / `MHD3D`（理想） | **8** | `plugins/MHD/MHDPhysicalModel.ci:49` |
| `MHD2DProjection` / `MHD3DProjection`（GLM，多一个 $\psi$） | **9** | `plugins/MHD/MHDProjection.ci:51`；`MHD3DProjectionCons.cxx:42-52` 第 9 个分量为 `phi` |
| `MHD2DProjectionDiff` / `MHD3DProjectionDiff`（电阻 MHD） | **9** | `plugins/MHD/MHDProjectionDiffPhysicalModel.ci:35` |
| `MHD2DProjectionPolytropic` / `MHD3DProjectionPolytropic` | **8** | `plugins/MHD/MHDProjectionPolytropic.ci:51` |
| `MHD2DProjectionEpsDiff` / `MHD3DProjectionEpsDiff` | **11** | `plugins/MHD/MHDProjectionEpsDiffPhysicalModel.ci:35` |


**波系**：理想 MHD 有 **8 个波**——熵波、Alfvén 波（$\times2$，速度 $u\pm v_A$，$v_A = B/\sqrt{\rho}$）、快/慢磁声波（各 $\times2$）。这比 Euler 的 3 个波复杂得多，也是 MHD 格式需要专门设计的原因（如 `AUSMPWMHD2D`/`AUSMPWMHD3D`，注册于 `plugins/FiniteVolumeMHD/AUSMFluxMHD.cxx`，**注意注册名带维度后缀，不存在无后缀的 `AUSMPWMHD`**）。

**散度约束 $\nabla\cdot\mathbf{B}=0$**：这是 Maxwell 方程的要求，但数值离散会破坏它，导致非物理力与不稳定。COOLFluiD 的两条对策：

1. **投影法**（`MHD2DProjection` 系列模型）：把 $\nabla\cdot\mathbf{B}\neq0$ 的部分投影掉（求解一个 Poisson 型修正）；
2. **熵稳定格式**（`EntropyMHD3D` 模型 + `EntropyMHD` 插件）：构造满足熵不等式的通量，从格式层面保证稳定。

### 3.2.5 热化学非平衡（NEQ）——高焓核心能力

**物理背景**：高超声速再入时激波层温度可达数千至上万 K，此时发生两种"非平衡"：

- **化学非平衡**：分子离解、电离反应速度有限，组分浓度跟不上温度变化（用**有限速率化学源项**描述，而非平衡常数）；
- **热力学非平衡**：不同能量模态（平动-转动 $T$、振动 $T_v$、电子 $T_e$）之间的能量交换速度有限，**各模态温度不相等**（这就是"双温度/多温度模型"）。

**为什么必须分开？** 振动模态的激发/弛豫特征时间比平转动长几个量级。飞行器激波后气体平动温度瞬间上万 K，而振动温度还停留在来流值——能量"卡"在平转动模态里，导致激波位置、壁面热流与完全平衡模型显著不同。

**多温度 NEQ 方程组**（以 $ns$ 个组分、$nv$ 个振动温度 + 电子温度为例）：

1. **组分连续方程**（$i=1..ns$）：

$$\frac{\partial \rho_i}{\partial t} + \nabla\cdot(\rho_i\mathbf{u}) = \nabla\cdot(\rho D_i\nabla y_i) + \underbrace{\dot\omega_i}_{\text{化学反应源项}}$$

2. **动量方程**（与 NS 同形式）；

3. **总能量方程**：

$$\frac{\partial \rho E}{\partial t} + \nabla\cdot(\rho H\mathbf{u}) = \nabla\cdot(k\nabla T + k_v\nabla T_v + \sum_i h_i \rho D_i\nabla y_i) + \underbrace{\dot\Omega^{ener}}_{\text{能量源项（辐射等）}}$$

4. **振动能方程**（$k=1..nv$，每个振动模态一个）：

$$\frac{\partial \rho e_{v,k}}{\partial t} + \nabla\cdot(\rho e_{v,k}\mathbf{u}) = \nabla\cdot(k_{v,k}\nabla T_{v,k}) + \underbrace{\dot\Omega_k^{VT}}_{\text{振动-平动弛豫源项}}$$

5. **电子能量方程**（可选）：

$$\frac{\partial \rho e_e}{\partial t} + \nabla\cdot(\rho e_e\mathbf{u}) = \nabla\cdot(k_e\nabla T_e) + \dot\Omega^{EE}$$

**源项的刚性**：化学反应与振动弛豫的特征时间可能比流动时间小几个数量级，造成**刚性（stiff）**——这是 NEQ 隐式求解（必须解析 Jacobian）与 CFL 爬升策略的物理原因。

### 3.2.6 局部热力学平衡（LTE）

**物理假设**：化学反应与能量交换速率无限快，气体**处处处于当地平衡态**——组分浓度与热力学状态只由 $(p,T)$ 两个变量决定（通过平衡常数/质量作用定律求组分）。此时无需额外的组分/振动能方程。

**与 NEQ 的选择判据**：

| 条件 | 选择 |
|------|------|
| 低高度、高密度、弛豫时间 $\ll$ 流动时间 | **LTE**（方程少、快、鲁棒） |
| 强激波层、稀薄条件、高空再入 | **NEQ**（必须追踪非平衡过程） |

**两种接入方式**：

1. **专用模型**：`Euler2DLTEDemix`、`Euler3DLTEDemix`（`LTE` 插件）：平衡组分（demix 扩散）+ 平衡热力学/输运；
2. **LTE 变量集 + LTE 物性库**：标准模型（如 `NavierStokes2D`）配 `PuvtLTE`/`PvtLTE`/`PrvtLTE` 变量集与 LTE 输运库——`bluntBodyKheopsNS_DIM_LTE.CFcase` 即采用 `PhysicalModelType = NavierStokes2D` 的方式运行 LTE。

算例对照见第 7.3 节（高超声速档案，含 `bluntBodyKheops*` 族）。

### 3.2.7 辐射传输方程（RadiativeTransfer）

**物理背景**：高焓流场中，高温气体（尤其是离解的原子/分子）会**发射和吸收辐射**。对 Apollo 级再入，辐射热流可占总热流的相当份额。

**辐射传输方程（RTE）**——沿方向 $\mathbf{s}$、频率 $\nu$：

$$\mathbf{s}\cdot\nabla I_\nu = \kappa_\nu\left(I_{b,\nu} - I_\nu\right)$$

$I_\nu$ 为光谱辐射强度，$\kappa_\nu$ 为吸收系数，$I_{b,\nu}$ 为 Planck 黑体函数。对全方向积分得到**辐射热流** $\mathbf{q}_{rad}=\int\int I_\nu\mathbf{s}\,d\Omega\,d\nu$，其散度作为能量源项进入流动方程：

$$\nabla\cdot\mathbf{q}_{rad} = -\dot\Omega_{rad} \quad(\text{代码中对应}\ \texttt{omegRad})$$

**求解器与模型**（`RadiativeTransfer` 插件，232 文件）：

- **谱带模型**（`RadiationLibrary/Models/`）：`HSNB`（高谱分辨率窄带）、`PARADE`、`Grey`（灰气体）、`ArcJet`、`Reflection`、`Null`；
- **求解器**（`Solvers/`）：`FiniteVolumeDOM`（离散坐标法，把方向空间离散成若干"纵坐标"）、`FiniteVolumeSolar`、`MonteCarlo`（蒙特卡洛，光子追踪，精度高但有统计噪声）。

**耦合方式**：流场提供 $(T, T_v, y_i)$ → 辐射体计算谱吸收/发射 → 净辐射源项 `omegRad` 回写 NEQ 能量方程（见 4.15.3 节）。辐射算例见第 7.2.4 节（`slab2d` MonteCarlo 验证族）。

### 3.2.8 壁面现象：催化与表面过程

高焓流中壁面不只是"边界"，还参与化学反应：**来流的氧原子在壁面复合成 $O_2$，释放复合热**，显著提高壁面热流。

| 壁面模型 | 数学条件 | 物理含义 |
|----------|----------|----------|
| 完全催化（FCW） | $y_i|_{wall} = y_i^{eq}(T_w,p)$ | 壁面处组分立即回到平衡，复合热最大，热流最高 |
| 完全非催化（NCW/PMC） | $\partial y_i/\partial n|_{wall}=0$ | 壁面不参与反应，热流最低 |
| 有限催化（PCW） | $\rho D_i \partial y_i/\partial n = k_w \rho y_i$ | 用复合系数 $\gamma$（代码中 `Catalycity` 相关参数）刻画有限反应速率 |

**代码框架**：`Framework/CatalycityModel`（继承 `PhysicalPropertyLibrary`）为催化模型抽象，Null 实现默认关闭；具体催化壁 BC：`NoSlipWallIsothermalNSrvtCatFVMCC`、`NoSlipWallIsothermalNSrvtCatMultiFVMCC`、`NoSlipWallIsothermalNSrvtCatRFVMCC`、`NoSlipWallIsothermalNSrvtCat_nadFVMCC`（均实现于 `plugins/FiniteVolumeNEQ/NoSlipWallIsothermalNSrvtCat.cxx`，见 3.6.3 节）。

**壁面热条件**：等温（`Isothermal`，$T=T_w$）、绝热（`Adiabatic`，$\partial T/\partial n=0$）、给定热流（`Heated`，$q=q_w$）、流固耦合壁（`CoupledNoSlipWall*`，由耦合器提供 $T_w$ 或 $q_w$）。

### 3.2.9 等离子体模型（ICP / ArcJet）

等离子体是部分电离的气体，需要同时描述流动与电磁场。两类典型装置：

| 模型注册名 | 说明 | 插件 |
|------------|------|------|
| `ICPLTE2D/3D`、`ICPNEQ2D/3D` | 电感耦合等离子体炬（ICP）：线圈感应产生电磁场加热气体，LTE/NEQ 两种物性 | `ICP` |
| `ArcJet2D/3D`、`ArcJetLTE2D/3D`、`ArcJetPG2D/3D`、`ArcJetSALTE2D/3D`、`EulerArcJet2D/3D` | 电弧加热器（ArcJet）：电弧放电加热气流，多种物性方案组合 | `ArcJet` |

**数学特征**：在 N-S 方程基础上增加

1. **洛伦兹力源项**（动量方程）：$\mathbf{f}_L = \mathbf{J}\times\mathbf{B}$；
2. **焦耳热源项**（能量方程）：$\dot Q_J = \mathbf{J}\cdot\mathbf{E} = \lvert\mathbf{J}\rvert^2/\sigma_e$（$\sigma_e$ 为电导率）；

这就是 3.4 节表中 `Poisson*` 模型的重要用途——**它们是等离子体/电磁场的配套求解器，而非孤立的数学练习**。

## 3.3 方程的数学性质：为什么算法长这样

这一节是**第 4 章的理论基础**。理解了它，第 4 章的所有格式（Roe、HLL、AUSM、迎风、CFL）都不再是"魔法公式"，而是有明确动机的构造。

### 3.3.1 双曲性与 Jacobian 矩阵

把守恒律写成"拟线性"形式（以一维 Euler 为例）：

$$\frac{\partial U}{\partial t} + A(U)\frac{\partial U}{\partial x} = 0,\qquad A = \frac{\partial F}{\partial U}$$

$A$ 叫**通量 Jacobian 矩阵**。若 $A$ 有 $m$ 个**实特征值**和完备的**特征向量组**，则方程组是**双曲型**的——意味着信息以有限速度（特征值）沿特征方向传播，这是"迎风"概念的基础。

### 3.3.2 Euler 方程的特征值与波系

一维 Euler 的 Jacobian 有三个特征值：

$$\lambda_1 = u - a,\qquad \lambda_2 = u,\qquad \lambda_3 = u + a$$

**物理含义**：三个波以这三种速度传播——

| 波 | 速度 | 携带的信息 |
|----|------|-----------|
| 声波（左行） | $u-a$ | 压力/速度扰动 |
| 熵波/涡波 | $u$ | 熵、涡量（随流体输运） |
| 声波（右行） | $u+a$ | 压力/速度扰动 |

**马赫数就是流动速度与声速之比** $M=u/a$：

- $M<1$（亚声速）：$u-a<0<u+a$，**有波向上游传播** → 下游信息能影响上游 → 边界条件需按传播方向分别给定（这就是"亚声速入口给总温总压、出口给静压"的原因）；
- $M>1$（超声速）：三波全向下游 → 信息只向下游传播 → 入口必须给全部变量，出口全部外推。

**代码实现**：特征值由变量集计算（如 `computeEigenValuesVectors(_rightEv, _leftEv, _eValues, unitNormal)`），是 Roe 型格式的输入（4.4.3 节）。

### 3.3.3 Jacobian 的投影与对角化

多维情况下，取面法向 $\mathbf{n}$，定义**投影 Jacobian**：

$$A_n = \frac{\partial(\mathbf{F}\cdot\mathbf{n})}{\partial U} = \frac{\partial F}{\partial U}n_x + \frac{\partial G}{\partial U}n_y \quad(\text{2D})$$

可对角化：$A_n = R\Lambda R^{-1}$，其中 $R$ 为右特征向量矩阵（列向量为特征向量），$\Lambda = \mathrm{diag}(\lambda_i)$ 为特征值对角阵。

**代码中完全对应**（`RoeFlux.cxx:147-163`）：

```cpp
// 计算线化 Jacobian 的特征向量与特征值
solutionVarSet->computeEigenValuesVectors(_rightEv,   // R  （右特征向量矩阵）
                                          _leftEv,    // R⁻¹（左特征向量矩阵）
                                          _eValues,   // Λ  （特征值）
                                          unitNormal);// n  （面法向）
setAbsEigenValues();   // 计算 |Λ|，并在此处施加熵修正/carbuncle 修正
```

| 代码变量 | 数学符号 | 含义 |
|----------|----------|------|
| `_rightEv` | $R$ | 右特征向量矩阵 |
| `_leftEv` | $R^{-1}$ | 左特征向量矩阵（行向量） |
| `_eValues` | $\Lambda=\mathrm{diag}(\lambda_i)$ | 特征值 |
| `_absEvalues` | $\lvert\Lambda\rvert$ | 特征值绝对值（耗散强度） |
| `unitNormal` | $\mathbf{n}$ | 面单位法向 |

### 3.3.4 Riemann 问题：格式设计的出发点

**Riemann 问题**：给定界面左右两个常状态 $U_L,U_R$，求解其相互作用后的演化。有限体积法中，**每个网格界面都是一个局部 Riemann 问题**——重构给出左右态（4.3 节），通量格式求解它（4.4 节）。

Riemann 问题的精确解含三个波（激波/接触间断/膨胀波），精确 Riemann 求解器迭代求解、代价高；实用格式都用**近似 Riemann 求解器**：

| 格式 | 思路 | 代码注册名 |
|------|------|-----------|
| Roe | 用 Roe 平均态线性化，$F=\tfrac12(F_L+F_R)-\tfrac12\lvert A\rvert(U_R-U_L)$ | `Roe` 族 |
| HLL/HLLE | 只分辨最快的两（三）个波，用波速估计直接给出通量 | `HLL`、`HLLE` |
| AUSM 族 | 把通量拆成对流（质量流）+ 压力两部分分别处理 | `AUSM*` |
| 中心格式 | 不分辨波，取平均 + 人工耗散 | `Centred` |

详细公式与源码见 4.4 节。

### 3.3.5 熵条件：为什么需要"修正"

双曲守恒律的**弱解不唯一**，必须附加**熵条件**才能选出物理正确的解（激波必须是压缩的，不能是膨胀激波）。数值格式的对应问题：

- **膨胀激波**：某些格式（如未修正的 Roe）在声速点附近耗散不足，会算出非物理的膨胀激波 → 需**熵修正**（`entropyFixID`）；
- **Carbuncle 现象**：强激波（$M>5$）沿网格对齐时，Roe 格式会算出非物理的"红玉"状畸变 → 需 **carbuncle 修复**（`RoeSA`， Sanders 等修正）。

代码中熵修正就在 `setAbsEigenValues()` 里（见 3.3.3 的代码）——**这是把数学要求落到代码的最直接例子**：数学上要"修正特征值"，代码上就"改 `_absEvalues` 的取值规则"。

## 3.5 数值离散方法总览

前面解决了"方程是什么"，本节回答"**用什么数值方法把这些方程变成代数方程**"。详细算法见第 4 章，此处给出统一的选型视图。

### 3.5.1 统一视角：加权残差框架

所有本章方法都可纳入同一框架。设方程残差 $R_h = \partial_t U_h + \nabla\cdot\mathbf{F}(U_h) - \ldots$，要求它在**检验函数（test function）** $\varphi$ 张成的空间上正交：

$$\int_\Omega R_h\,\varphi\,dV = 0,\qquad \forall \varphi\in\mathcal{V}_h$$

| 方法 | 检验函数 $\varphi$ 的选择 | 结果 |
|------|---------------------------|------|
| **有限体积（FVM）** | 单元指示函数（$\varphi=1$ 在本单元，0 在其他） | 得到**逐单元的守恒律**，通量在界面求和 |
| **有限元（FE/DG）** | 与解同空间的多项式基函数 | 得到**弱形式**的代数方程组 |
| **残差分布（RDS）** | 节点型（线性）基函数 | 得到**逐节点的分布律** |
| **通量重构（FR）** | 修正函数（correction function） | 高阶通量多项式 + 界面修正 |

**共同点**：最终都归结为"计算残差 $R_i$ → 用某种时间推进求 $R_i=0$"。**差别**在于残差怎么算（模板宽度、多项式阶、守恒性），这决定了精度、鲁棒性与代价。

### 3.5.2 有限体积法（FVM）——单元中心

- **插件**：`FiniteVolume`（通用内核，381 文件）+ 按物理扩展的 `FiniteVolumeNavierStokes/NEQ/MHD/MultiFluidMHD/Maxwell/ICP/ArcJet/Turb/GReKO/LES/Combustion/Poisson/PoissonNEQ`；
- **注册名**：`CellCenterFVM`；配套策略：通量格式（FluxSplitter）、重构（PolyRec）、限制器（Limiter）、RHS 计算策略（`NumJacob/AnalyticalJacob`）；
- **数学本质**：对单元 $i$ 积分守恒律，用散度定理把体积分变面积分：

  $$\frac{d}{dt}\int_{\Omega_i}U\,dV = -\oint_{\partial\Omega_i}\mathbf{F}\cdot\mathbf{n}\,dS \approx -\sum_{f\in\partial\Omega_i}\hat{\mathbf{F}}_f A_f$$

  未知量是**单元平均值**（单元中心法），二阶精度靠重构（4.3 节）；
- **定位**：工程基线方法，鲁棒、功能最全（动网格/并行/隐式/所有物理均有通道）。

### 3.5.3 残差分布法（RDS / FluctSplit）——节点中心

- **插件**：`FluctSplit`（920 文件）+ `FluctSplitNEQ`；显式推进配 `RKRD`；
- **数学本质**：未知量在**网格节点**上。对每个单元 $T$ 计算总残差（fluctuation）

  $$\phi^T = \oint_{\partial T}\mathbf{F}\cdot\mathbf{n}\,dS \approx \sum_{j\in T}K_j U_j$$

  再按**分布系数** $\beta_i$ 把 $\phi^T$ 分给三个顶点：$\phi_i = \beta_i\phi^T$，要求 $\sum_i\beta_i=1$（**守恒性**）。LDA 为多维迎风（无耗散、二阶精度），N 格式为一阶迎风（正型、单调）；
- **定位**：VKI 特色方法，精度/鲁棒性俱佳，是高焓算例群（DoubleEllipse RDS 版本）的传统主力；BC 命令以 `Strong*` 前缀命名（3.6.4 节）；详细算法见 4.9 节。

### 3.5.4 间断伽辽金（DG）

- **插件**：`DiscontGalerkin`（51 文件）；
- **数学本质**：单元内解为 $P$ 阶多项式，单元间**允许间断**，界面用数值通量耦合；弱形式：

  $$\int_{\Omega_i}\frac{\partial U_h}{\partial t}\varphi\,dV - \int_{\Omega_i}\mathbf{F}(U_h)\cdot\nabla\varphi\,dV + \oint_{\partial\Omega_i}\hat{\mathbf{F}}\varphi\,dS = 0$$

- **定位**：高阶基准实现，含局部投影限制器；物理覆盖相对 FR/SD 较窄。

### 3.5.5 通量重构（FR / CPR）——当前高阶主线

- **插件**：`FluxReconstructionMethod`（内核，488 文件）+ 物理扩展（`FluxReconstructionNavierStokes/Turb/MHD/MultiFluidMHD/EntropyMHD/Poisson/NEQ`）+ GPU（`FluxReconstructionCUDA`）与 PETSc 通道；
- **数学本质**：在单元内布置 $P+1$ 个**解点**（solution points）与 $P+2$ 个**通量点**（flux points）。解点上的值插值得连续通量多项式，与界面公共通量的差用**修正函数** $g$ 传播回单元内：

  $$\hat{\mathbf{F}}(\xi) = \tilde{\mathbf{F}}(\xi) + \left[\hat{F}_L - \tilde{F}(-1)\right]g_L(\xi) + \left[\hat{F}_R - \tilde{F}(1)\right]g_R(\xi)$$

  修正函数 $g$ 的选取**统一了多种高阶格式**：取不同 $g$ 可分别恢复 DG、SD（谱差分）、Huynh 格式。COOLFluiD 用 **VCJH 族**（单参数 `CFactor`）在这条谱上连续插值（4.10 节）；
- **能力**：多项式阶由 `CFPolyOrder` 枚举 `P0`–`P10` 表示，实际可用上限受单元类型的形函数/求积实现限制（Tensor 型 Quad/Hexa 最高，Triag/Tetra 较窄），选定前请参照插件 `testcases` 中实际跑通的阶次（如 `Cylinder/` 下的 `cylinderEuler2DFR-impl_P4/P5/P6/P8`）；支持隐式（BackwardEuler + PETSc）与 JFNK 变体；
- **定位**：当前高阶研究主线（手册：`doc/Manuals/FluxReconstructionManual.pdf`）。

### 3.5.6 谱差分（SD）与谱体积（SV）

- **插件**：`SpectralFD`（内核）+ `SpectralFDNavierStokes/LES/LinEuler`；`SpectralFV` + `SpectralFVNavierStokes`；
- **SD 数学本质**：解点与通量点**交错布置**，直接对通量做插值——无需求积分，效率高；
- **SV 数学本质**：单元划为若干**子单元**（谱体积），在每个子单元上做有限体积更新，兼具 DG 紧凑性与 FVM 守恒性；
- **能力**：P1–P5 收敛族算例（AccPulse）；粘性处理 BR2/IP/LocalApproach 三路线（`SpectralFDNavierStokes`）。

### 3.5.7 有限元（FE）

- **插件**：`FiniteElement`（165 文件）：弹性结构与输运问题的弱形式装配，与 `StructMech` 物理配套。

### 3.5.8 方法选择决策树

```
问题是什么？
├─ 工程 Fluent 替代 / 全物理通道 / 大规模并行隐式 ──► FVM（CellCenterFVM）
├─ 高焓非平衡，追求节点中心精度与鲁棒 ────────────────► RDS（FluctSplit + FluctSplitNEQ）
├─ 高阶精度研究（格式论文 / 收敛阶验证）
│   ├─ 要隐式+PETSc、多物理扩展全 ──────────────────► FR（FluxReconstructionMethod）
│   ├─ 要 SD 路线 / 粘性处理对比（BR2/IP/LA）────────► SD（SpectralFD）
│   └─ 要亚单元有限体积守恒 ─────────────────────────► SV（SpectralFV）
├─ MHD / 多流体等离子体 ───────────────────────────► FVM（FiniteVolumeMHD/MultiFluidMHD）
│                                                      或 FR（FluxReconstructionMHD）
└─ 固体力学 / 导热 ────────────────────────────────► FVM/FE（Heat、StructMech、FiniteElement）
```

> **提示**：同一物理在不同方法下的算例常成对出现（如 `cyl_Pg_M15_FVM_1st2nd.CFcase` 与其 RDS 重启前序、AccPulse 的 FVM/FR/SD/SV 并联族），可直接用于方法对比（第 7.2.2 节）。

## 3.6 边界条件的数学形式与命令体系

### 3.6.1 为什么边界条件这么讲究：特征分析

边界条件**不能随意指定**，指定的数量必须与"从域外传入的波"数量一致。以二维 Euler（4 个方程）为例，设边界外法向速度为 $u_n$：

| 流动状态 | 进入域内的波数 | 应指定的边界条件数 | 其余量 |
|----------|----------------|--------------------|--------|
| 超声速入口（$M_n>1$） | 4 | **4 个（全部）** | 无（全部外推） |
| 亚声速入口（$0<M_n<1$） | 3 | **3 个** | 1 个由内场外推 |
| 亚声速出口（$0<M_n<1$） | 1 | **1 个**（如静压） | 3 个外推 |
| 超声速出口（$M_n>1$） | 0 | **0 个** | 4 个全部外推 |

**这就是为什么"亚声速出口只给静压"是正确做法**，而"亚声速出口给所有变量"会导致反射与不收敛。COOLFluiD 的 `SuperOutlet`（只给压力、其余外推）与 `FarField*Char*`（特征化远场）正是按此设计的。

### 3.6.2 常见边界条件的数学表达

| 边界类型 | 数学条件 | 虚拟态（ghost state）构造 | 代表命令 |
|----------|----------|---------------------------|----------|
| 超声速入口 | $U_g = U_\infty$ 全给定 | 直接赋值 | `SuperInletFVMCC` |
| 亚声速出口 | $p=p_{out}$，其余 $\partial/\partial n=0$ | $U_g = U_{inner}$，$p$ 改给定值 | `SuperOutletFVMCC` |
| 远场（特征） | 按 $u_n\pm a$ 分解入/出射波，入射波用自由来流值 | 特征化组合 | `FarFieldEulerChar2DFVMCC` |
| 滑移/对称面（镜面） | $u_n=0$，$\partial u_t/\partial n=0$，$\partial p/\partial n=0$ | $U_g = U_{inner} - 2(\mathbf{u}\cdot\mathbf{n})\mathbf{n}$（**速度法向分量反号**） | `MirrorVelocityFVMCC` |
| 无滑移等温壁 | $\mathbf{u}=0$，$T=T_w$ | $U_g$：速度反号（$-u$），温度 $2T_w - T_{inner}$（保证面心为 $T_w$） | `NoSlipWallIsothermalNS2DFVMCC` |
| 无滑移绝热壁 | $\mathbf{u}=0$，$\partial T/\partial n=0$ | 速度反号，温度取内场值 | `NoSlipWallAdiabaticNS2DFVMCC` |
| 给定热流壁 | $\mathbf{u}=0$，$-k\partial T/\partial n = q_w$ | 温度按 $q_w$ 构造梯度 | `NoSlipWallHeatedNS2DPuvtFVMCC` |
| 周期边界 | $U(\mathbf{x}+L)=U(\mathbf{x})$ | 直接映射到对面单元 | `BCPeriodicFVMCC` |
| 完全催化壁（NEQ） | $y_i=y_i^{eq}(T_w,p)$ | 组分置平衡值 | `NoSlipWallIsothermalNSrvtCatMultiFVMCC` |

> **虚拟态公式的意义**：以等温壁温度 $T_{ghost}=2T_w-T_{inner}$ 为例——面心温度是内外两侧的算术平均 $\tfrac12(T_{ghost}+T_{inner})=T_w$，**恰好等于给定壁温**。这类"反推虚拟态"的构造是理解 BC 命令实现的关键（3.6.5 节）。

**源码验证 1：镜面（滑移）边界**——`plugins/FiniteVolumeNavierStokes/MirrorEuler2D.cxx:80-81`

```cpp
_dataGhostState[EulerTerm::RHO] = _dataInnerState[EulerTerm::RHO];              // ρ_g = ρ_i
_dataGhostState[EulerTerm::VX]  = _dataInnerState[EulerTerm::VX] - 2.0*vn*nx;   // u_g = u_i - 2 v_n n_x
```

其中 `vn = u·n` 为法向速度（:74-75）。与表中公式 $U_g=U_{inner}-2(\mathbf u\cdot\mathbf n)\mathbf n$ **逐项一致**：法向分量反号（$-2v_n$ 使 $u_{g,n}=-u_{i,n}$），切向分量不变，密度与压力不变。

**源码验证 2：无滑移等温壁**——`plugins/FiniteVolumeNavierStokes/NoSlipWallIsothermalNS2D.cxx:100`

```cpp
CFreal ghostT = 2.*_wallTemp - innerT;      // T_g = 2T_w - T_inner  ← 与表中公式一致
```

代码在此之外还做了一件文档容易忽略的事——**正定性保护**（:102-108）：当 $2T_w-T_{inner}<0$（壁面很冷或内场很热）时，虚拟温度会变负，导致密度/压力非物理。代码通过**动态移动 ghost 节点位置**解决：

```cpp
CFreal factor = 1.;
while (ghostT < 0.) {
  _tempNode = 0.5*(_midNode + _tempGhostNode);          // ghost 节点向边界靠拢
  factor *= 2.;                                          // 权重因子翻倍
  ghostT  = ((factor + 1.)*_wallTemp - innerT)/factor;   // 加权平均形式的壁温条件
  _tempGhostNode = _tempNode;
}
cf_assert(ghostT > 0.);
```

随后按"面心插值"反推各量（:112-120）：$\rho_g=p_i/(R\,T_g)$（压力取内场值、密度由状态方程反算）、$\mathbf u_g=-\mathbf u_i/\text{factor}$（速度反号并随节点位置缩放，使**面心速度为 0**，满足无滑移）。

> **这段代码揭示了 BC 实现的两条通用经验**：① 虚拟态不是"随便给个值"，而是**由面心条件反推**出来的（面心是内/外的算术平均，因此"面心 = 给定值"等价于"虚拟态 = 2×给定值 − 内场值"）；② 所有虚拟态构造都必须保证**物理量正定**（密度、温度、压力 > 0），否则第 1 步残差就是 NaN。

### 3.6.4 RDS / FR / SD / SV 的边界条件命令族

- **RDS（FluctSplit）**：命名无 `FVMCC` 后缀，强加型边界以 `Strong` 前缀标示实现方式，如 `StrongNoSlipWallIsothermalNS2D`（+`Impl` 隐式变体）、`StrongNoSlipWallAdiabaticNS3D`、`StrongFarFieldNonRefEuler2DCons`、`CoupledSuperInlet`、`LinEuler2DSourceWall`；
- **FR**：BC 位于内核与物理扩展插件（如 `SuperOutlet`、`WallCutOffDistance` 等），命名风格与物理模型绑定，随 FR 物理扩展清单给出（第 6.2.8 节）；
- **SD/SV**：BC 命令位于对应方法/物理插件，命名沿用"物理 + 变量集 + 方法"模式。

各方法的 BC 实现均基于"虚拟态（Ghost State）+ 数值通量"或"强加约束"两条路线，物理语义一致，可跨方法对照学习。

### 3.6.5 TRS 绑定与虚拟单元机制

**配置四段式**：CFcase 中以"命令类型列表（`BcComds`）+ 实例名列表（`BcNames`）+ 逐实例参数（`<名字>.<选项>`）+ 绑定 TRS（`applyTRS`）"配置（完整语法见第 9.3.9 节）。

**TRS（Topological Region Set）与网格边界标记的对应**：

1. CFcase `Simulator.SubSystem.Default.listTRS = InnerFaces NoSlipWall SuperInlet SuperOutlet`（名字任意，顺序即 TRS 编号习惯来源）；
2. 每个名字必须与 `.CFmesh` 文件中的 TRS 定义（网格转换器从 Gmsh/CGNS/Gambit 的物理边界名映射而来）**一一对应**，否则 setup 报"TRS not found"；
3. BC/初始化命令经 `<命令实例>.applyTRS = <TRS名或编号>` 绑定；一个 TRS 可绑定多个命令，一个命令也可绑定多个 TRS（如 `BcOutlet.applyTRS = 2 4`）；
4. `InnerFaces` 是内部面 TRS 的约定名（网格读取器自动生成），用于初始化命令（如 `InField.applyTRS = InnerFaces`）而非 BC；
5. 未设 BC 的边界 TRS 需显式声明豁免（FVM：`Data.TRSsWithNoBC`），否则一致性检查报警。

**虚拟单元机制**：

- FVM 类方法中，边界 BC 的本质是**更新边界面的虚拟态（Ghost/Dummy State）**：命令在每次 RHS 计算/迭代内被调用，按其物理语义写入虚拟单元状态（外推、反射、给定值、特征波信息……），随后通量计算把虚拟态当作普通邻单元处理——**这就是为什么 BC 命令要在每次残差计算时执行，而不是只在初始化时执行一次**；
- 虚拟态的分配与更新由内核 `ComputeDummyStates` 与各 BC 命令协作完成（并行时含跨 rank 的 Ghost 通信）；
- 强加型 BC（RDS 的 `Strong*` 族）则直接改写边界自由度，常配 `Impl` 变体参与隐式矩阵；
- 自定义 BC 的开发路径（继承 FVMCC BC 基类、声明套接字、注册 Provider）见第 11.4 节（新增边界条件教程）。

## 3.7 无量纲化与单位约定

### 3.7.1 有量纲 / 无量纲模式

- 算例文件名中的 `_DIM` / `_NDIM` 后缀标识该算例采用有量纲/无量纲设置（如 `bluntBodyKheopsNS_DIM_NEQ.CFcase`）；
- 模型层面并无全局"无量纲开关"：**无量纲与否完全由参考值（`refValues`）与输运参数（`Reynolds` 等）的取值方式决定**——
  - 有量纲模式：`refValues` 给真实参考态。典型 2D 完全气体四元组示例见 `plugins/NavierStokes/testcases/LongShotProbe/bluntbody-start.CFcase:24` 的 `refValues = 180000. 2500. 300. 2500.`（行内注释 `#p u v T`，即 p=1.8×10⁵ Pa、u=2500 m/s、v=300 m/s、T=2500 K）。⚠️ 旧版误将此例标注为"Fire II"——**FireII 的 `refValues` 是 NEQ 多值形式**（`plugins/NEQ/testcases/TCNEQ/FireII/fire2_1643s_TCNEQ.CFcase` 实测为 `1e-12 1e-6 1e-6 0.00059826 1e-6 0.00018174 1e-6 1e-6 1e-6 1e-6 1e-6 10480. 10480. 276. 276.`，共 15 个量，覆盖组分与多温度参考值），二者不可混用；
  - 无量纲模式：参考值归一（`refValues = 1. 1. 1. 1.` 类），粘性以 `Reynolds` 数给定（如 `doubleEllipseNS_PG.CFcase` 的 `DiffTerm.Reynolds = 17212.3847`）。

### 3.7.2 参考量定义与换算公式

- **`refValues` 的语义**（源码与算例注释确认）：2D 为 **p、u、v、T** 四个参考值；3D 为 **p、u、v、w、T** 五个（`bluntbody-start.CFcase` 内注释 `#p u v T`；`BLAST` 算例五值）；
- **无量纲化换算**（以 2D 为例，带 `*` 者为无量纲量）：

  $$p = p^*\,(\rho_\infty V_\infty^2),\quad \mathbf{u} = \mathbf{u}^*V_\infty,\quad T = T^*T_\infty,\quad \rho = \rho^*\rho_\infty,\quad x = x^*L$$

  其中 $\rho_\infty$ 由 $p_\infty = \rho_\infty R T_\infty$ 推出，因此 `refValues` 只需给 $(p,u,v,T)$ 四/五个量；
- **`refLength`**：参考长度（如双椭球 0.76 m），用于雷诺数与坐标缩放；
- **`machInf` / `tempRef`**：对流项侧的自由来流马赫数与 Sutherland 参考温度（`ConvTerm.machInf/tempRef`）；
- **输出量**：结果文件中的变量始终以**当前变量集**输出（如 `Puvt` → p,u,v,T），`Tecplot.Data.outputVar/updateVar` 可切换（第 10.1.1 节）；换算回物理单位时用 `refValues` 逐量回乘；
- **约定**：全书示例 CFcase 均在相应行内注明各参考值含义；新算例建议仿照 `bluntbody-start.CFcase` 在行尾加 `#p u v T` 注释。
