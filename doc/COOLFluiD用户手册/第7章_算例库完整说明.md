# 第 7 章 算例库完整说明

本章把第 6 章的"验证算例索引"展开为**逐算例档案**。每个档案固定回答六件事：

1. **物理背景**：算什么、验证什么；
2. **几何模型与网格**：文件、拓扑、阶次；
3. **边界条件设置**：`BcComds/BcNames` 与关键取值；
4. **求解器配置**：方法、通量、时间推进、LSS 与收敛判据；
5. **后处理建议**：输出什么、用什么命令读；
6. **预期结果与参考数据**：残差目标、与文献/实验的对照点。

档案中的一切键与取值均直接取自 `plugins/<名>/testcases/` 下的真实 CFcase（以"实测"标注）。运行方式统一为（第 0.3 节）：

```
./coolfluid-solver --scase plugins/<名>/testcases/<算例>/<文件>.CFcase
```

## 7.1 算例库总览

### 7.1.1 目录组织约定

- **三级结构**：`plugins/<插件>/testcases/<算例集>/<若干 CFcase>`；同集内多个 CFcase 表达"同一问题的不同方法/阶次/工况"（如 `cylinderNS2DFR_P0…_P9`）；
- **文件名语义**：前缀=算例（`cyl`、`wedge`、`naca`），中缀=方法/变体（`FVMImpl`、`FluctSplit`、`sfdm`、`FR`、`FS_SpaceTime`、`CUDA`、`-impl`、`-par`、`-lusgs`、`QD`=拟二次网格、`HOCRD`=高阶 CRD），后缀=工况（`Re40`、`Ma_0.8_AoA_1.25`、`P5`）；
- **配套文件**：`*.CFmesh` 网格、`*.SP`（Tecplot 会话）/`*.thor`（Thor 源网格）、`*.neu`/`*.msh`/`*.dpl`（第三方网格）、`*.inter`（交互参数）、`*.START_*`（续算初场）、`*.con`/`*.dbs`（物性数据）；
- **头注释**：每个 CFcase 首段 `###` 元注释说明测试内容，`### Residual = …` 是作者标定的**收敛残差目标**，可直接作为判据。

## 7.2 基础验证算例档案

### 7.2.1 `burgersFVM`——Burgers 方程最小 FVM 模板（Burgers 插件）

- **物理背景**：一维非线性标量对流（Burgers）在 2D 网格上的迎风传播，验证 FVM 单元中心法的重构/限制器/BC 全链路，也是**新用户的第一份 CFcase**。
- **几何与网格**：`burgers.thor`（Thor 源网格）→ 运行期经 `THOR2CFmesh` 转换（`convertFrom = THOR2CFmesh`、`Discontinuous = true`、`SolutionOrder = P0`）生成 `burgersFVM.CFmesh`；三角形网格。
- **边界条件**：
  - `SuperInletFVMCC`（East/South/West，解析场给定 `Def = 1.5-2.*x`）；
  - `SuperOutletFVMCC`（North，`ZeroGradientFlags = 1`）。
- **求解器配置**（实测）：

```
SpaceMethod = CellCenterFVM
Data.FluxSplitter = Roe; Data.UpdateVar = Prim
Data.PolyRec = LinearLS2D; Data.LinearLS2D.limitRes = -14.
Data.Limiter = BarthJesp2D            # 备选 Venktn2D
SetupCom = LeastSquareP1Setup (stencil=FaceVertex)
ConvergenceMethod = FwdEuler; CFL.Value = 0.5
StopCondition = Norm; valueNorm = -5.0
```

- **后处理建议**：Tecplot 输出 `burgersFVM.plt`（SaveRate 200）；对比"传播速度=波速"理论解，检查激波厚度与过冲。
- **预期结果**：作者标定 `### Residual = -5.00048764`；迎风保单调，Barth 限制器下无新极值。

### 7.2.2 `accpulse2d` 族——高阶方法一致性验证（AccPulse）

- **物理背景**：等熵涡+声脉冲的"加速度脉冲"问题（Schwarzkopf 类），解光滑、无激波，适合做**精度阶次验证**（制造解替代品）。
- **几何与网格**：2D 周期矩形；`accpulse2d-sfdmP1-meshUpgrade.CFcase` 演示从粗网格 `MeshUpgrade` 升阶。
- **边界条件**：周期（经 `PeriodicBC` 命令族）。
- **求解器配置**（30 个 CFcase 覆盖）：

| 变体 | 配置要点（实测） |
|------|------------------|
| SD | `SpaceMethod = SpectralFDMethod`，P1–P5（`-P2-par`、`-P5-par` 等） |
| SD 网格升阶 | `accpulse2d-sfdmP1-meshUpgrade`（P0 网格→P1 解） |
| SD 隐式 | `-par-BDF2-InitCN`、`-par-CrankNich` |
| SD LU-SGS | `-par-lusgs-BDF2/BDF3/CrankNich`（±`-freezejacob`） |
| SV | `accpulse2d-sfvm`、`-sfvmQF`（`SpaceMethod = SpectralFVMethod`，RK2 推进） |
| FR | `accpulse2DFR.CFcase` |
| 3D | `accpulse3d-sfdmP1/P2/P3`、`accpulse3d-sfvm(-QF)` |
| 无量纲化 | `accpulse2d-sfdmP1-par-nondim` |

- **后处理建议**：按 P 阶次画误差-网格收敛线（期望斜率=阶次）；`convergence.plt` 对比 BDF2/CN/LU-SGS 迭代行为。
- **预期结果**：P 阶解点分布下达到理论收敛率；`-lusgs-freezejacob` 与完整 Jacobian 结果一致（LU-SGS 正确性验证）。

### 7.2.3 `twoPlatesFEM`——有限元热传导（Heat 插件）

- **物理背景**：3D 方块热传导（`Heat3D`，`Conductivity = 1.0`），两侧 Dirichlet 温度差驱动，体内含线性温度相关源项——验证 FE 空间残差/雅可比/数值积分。
- **几何与网格**：`cube.CFmesh`；`CFmeshFileReader.Data.builderName = FiniteElement`、`polyTypeName = Lagrange`（FE 构建器与多项式族）。
- **边界条件**：

```
BcComds = DirichletBC DirichletBC
BOUND1: Side1 → Def = 300   BOUND2: Side3 → Def = 500
（Vars = x y z t T，Implicit = false）
```

- **求解器配置**（实测）：

```
SpaceMethod = FiniteElementMethod
Data.UpdateVar = Prim; DiffusiveVar = Prim
Data.SourceVar = Heat3DSourceTDep; IndepDef = 2000*(y); LinearDef = 0.
Data.JacobianStrategy = Numerical; ResidualStrategy = StdElementComputer
IntegratorQuadrature = GaussLegendre; IntegratorOrder = P1
ConvergenceMethod = NewtonIterator; LinearSystemSolver = PETSC
NewtonIteratorLSS: PCASM/KSPGMRES/RCM/RelTol=1e-10/MaxIter=2000
```

- **后处理建议**：Tecplot `twoPlates.plt` 剖面温度线性段与源项弯曲段；与解析稳态解对比。
- **预期结果**：`### Residual = 4.63803`；温度场从 300 光滑过渡到 500，源项使剖面偏离纯线性。
- **同族**：`heat2D-FlexMG`/`heat3D-FlexMG`（多重网格）、`heat3D-Petsc`、`heat3D-SAMG`（SAMG 代数多重网格）、`heatedPlateTrilinos`（Trilinos 后端）——同一问题换 LSS 验证。

### 7.2.4 `slab2d`——辐射 MonteCarlo 验证（RadiativeTransfer）

- **物理背景**：2D 高焓板（气体温度 10000 K 量级）的**灰体辐射传输**，验证 `MonteCarlo` 算法与辐射-流场数据交换（`qrad` 输出到 Tecplot）。
- **几何与网格**：`slab2d.neu`（Gambit）→ `convertFrom = Gambit2CFmesh` 生成 `slab2d.CFmesh`；TRS：`InnerFaces Inlet Outlet BottomWall TopWall`。
- **边界条件**：
  - `SubInletEuler2DTtPtAlphaFVMCC`：`Ttot = 10000.0`、`Ptot = 160000.0`、`alpha = 0.0`（高焓超声入口）；
  - `NoSlipWallIsothermalNSvtFVMCC` ×2（`TWall = 10000.`、`Adiabatic = true`，Inlet/Outlet 侧壁）；
  - `MirrorVelocityFVMCC`（BottomWall 对称）。
- **求解器配置**（实测）：

```
SpaceMethod = CellCenterFVM; Data.FluxSplitter = Roe
UpdateVar = Puvt; SolutionVar = Cons; LinearVar = Roe; DiffusiveFlux = NavierStokes
PolyRec = Constant（一阶）
ConvergenceMethod = NewtonIterator; LSS = PETSC（PCASM/KSPGMRES/RCM/MaxIter=500）
DataProcessing1.Comds = RadiativeTransferMonteCarlo2DFVMCC
RT.applyTRS = InnerFaces; RT.numberOfRays = 10
RT.RadiationPhysicsHandler: NumberLoops=1, TempID=3, WavelengthMin=1e-10, WavelengthMax=1e10
aa: GreyRadiator（ElemEmsCoeff=1., ElemAbsCoeff=1., allIsGrey=true, 介质 InnerCells）
b1–b4: 四个边界辐射体（TypeTRS = Boundary）
```

- **后处理建议**：Tecplot 输出辐射量用 `Tecplot.Data.DataHandleOutput.CCSocketNames = qrad`（HuygensDLR 族实测用法；slab2d 本体仅输出主解场）；对比解析灰体平板辐射热流。
- **预期结果**：`### Residual = 0.137957`；`numberOfRays` 增大 → 辐射热流噪声下降（蒙特卡洛收敛）。
- **同族**：`cylinder3d/cylinderAxi`（DOM 变体）、`tangentSlab`（切平面近似）、`FireIIDLR/FireIIAxiMC`（FireII 谱带辐射，7.3.3 联动）。

## 7.3 高超声速与再入流动档案

### 7.3.1 `Cylinder` 圆柱——最全面的单问题多方法档案

- **物理背景**：超声速/高超声速圆柱绕流：**M∞=15 理想气体钝头激波**（`cyl_Pg_M15_*`）、**Re=40 粘性不可压**（`cylFVMImplPuvt_Reynolds_40`）、**Re=3900 圆柱分离 LES**（`cylFVMImplPuvt_LES_Re3900`）、M=0.15 层流（`cylinderNS2D*` 系）。
- **几何与网格**：曲边四边形网格族：`CylinderNSQuadCurved_16_5/32_9/128_33`、`cylinderNSQuadCurved.CFmesh`（Gambit `*.msh` 转换）、高阶族 `cylinderNSP3…P8.CFmesh`、`cylinderEulerP3…P8.CFmesh`；M15 族用 `cyl_Pg_M15.plt`（Tecplot 导入路径）。
- **边界条件**（以 `cylinderNS2DFR.CFcase` 实测）：`BcTypes = NoSlipWallHeatFluxNS2D Dirichlet`（Cylinder 壁 / FarField 自由来流）。
- **求解器配置**（68 个 CFcase，分族）：

| 族 | 配置（实测） |
|----|--------------|
| FVM 二阶 | `cyl_Pg_M15_FVM_1st2nd` / `cyl_Pg_M15_FVM_1st2nd_MeFiAlgo`（网格适配算法对比） |
| FR 显式 | `cylinderNS2DFR_P0…P9`：`FluxReconstruction`、`RiemannFlux = LaxFriedrichsFlux`、解点/通量点 `GaussLegendre`、`CorrectionFunctionComputer = VCJH`（`CFactor = 9.5e-4`）、`FwdEuler CFL=0.9`、`RelativeNormAndMaxIter(-6, 200000)` |
| FR 隐式 | `cylinderNS2DFR-impl_P0…P9`（双子系统：`SubSysMesh` 先 `MeshUpgrade.PolynomialOrder=P3` 升网格，再求解） |
| FR 曲线网格 | `Cylinder3DQuadCurved_16_5_2.CFmesh`（3D 曲边） |
| SD | `cylinderNS2D-sfdm-impl/-lusgs`、`cylinderNS2D-sfdmBR2/IP-lusgs`（粘性 BR2/IP 处理对比）、`cylinderNS2DCurved-sfdm-impl-par`（曲边） |
| SV | `cylinderEuler2D-sfvm-domModel` |
| LES | `cylinderLES2D-BR2/IP/LocalApproach-sfdm-P2P2-lusgs-Re40`、`-Re3900`、`cylFVMImplPuvt_LES_Re3900(-avg)` |
| CUDA | `cylinderNS2DFRCUDA.CFcase` |
| 验证收敛 | `gnoffoFR2DP0…P9`、`gnoffo1e-5*`（Gnoffo 超音速圆柱基准，`gnoffoFRP9.inter`） |

- **无量纲化要点**（`cylinderNS2DFR` 实测）：`refValues = 1.0 0.1774823934930 0.1774823934930 2.51575`，`DiffTerm.ViscosityLaw = FixedKinematicViscosity`、`KinVisc = 0.00443706`（Re=40 等价）。
- **后处理建议**：`cyl_Pg_M15.surf.plt` 提取驻点线；FR 族用 `WriteSolutionHighOrder` 输出到 ParaView（`.vtu`）比较 P0–P9 激波分辨率；LES 族统计 `-avg` 时均场。
- **预期结果**：M15 钝头激波脱体距离与驻点压力（对比 Fay-Riddell/文献）；`### Residual = -6.40585`（FR 族标定）；gnoffo 族对标 Gnoffo 数值基准；Re=40 分离泡长度 ≈ 2.2D；Re3900 平均阻力系数对照 LES 文献区间。

- **边界条件**：高超声速自由来流 + 等温/绝热壁族（各 CFcase 的 `SuperInlet*/NoSlipWall*` 命令族）。
- **求解器配置**（13 个 CFcase）：

### 7.3.3 `FireII`——飞行再入 TCNEQ 基准（NEQ 插件）

- **几何与网格**（路径实测更正）：两组算例**不在 `NEQ/testcases/` 顶层**，而在 TCNEQ 组下——

- **边界条件**：高焓自由来流；催化/非催化壁变体（`NoSlipWallIsothermalNSrvtCat*` 命令族，第 3.6.3 节）。

### 7.3.4 `DoubleCone` Run42——Holden 双锥（NEQ/TCNEQ）

- **物理背景**：CUBRC LENS 风洞 Holden 双锥（Run 42，N₂ 介质）——激波/边界层干扰导致分离再附的非平衡验证难题，CFD 界经典"竞赛"算例。
- **几何与网格**（路径实测，2026-09 复核修正）：算例位于 **`plugins/NEQ/testcases/TCNEQ/DoubleCone/`**，其下**只有一组**工况目录——`Run42_N2/`（2 个 CFcase：`DConeN2_42_FVM.CFcase`、`DConeN2_42_CRD_Weak.CFcase`）。

## 7.9 运行、续算与后处理指南

1. **运行**：`./coolfluid-solver --scase <路径>.CFcase`；`--ldir` 指定插件库目录；`--testEnv` 预检（第 0.3.7 节）；MPI：`mpirun -np N ./coolfluid-solver --scase …`（`-par` 后缀算例已验证并行）。
2. **输出约定**（全部以 CFcase 中 `Simulator.Paths.ResultsDir` 为根）：

| 文件 | 来源 | 用途 |
|------|------|------|
| `*.plt` / `*.vtu` | TecplotWriter/ParaViewWriter | 主解场 |
| `convergence.plt` | ConvergenceMethod | 残差-迭代曲线 |
| `aeroCoef*.plt/.dat` | AeroCoef/NavierStokesBLExtractionCC | Cl/Cd、Cf、热流 |
| `distances.dat`、`rms*.plt` | ComputeWallDistance*/RMS | 壁面距离、时均统计 |
| `*.CFmesh` | CFmeshFileWriter | 解+网格（续算输入） |

3. **续算**：把目标 CFcase 的 `MeshCreator` 指向上一轮的 `.CFmesh`（含解），并改 `InitialField`/`Restart` 相关键；仓库自带演示：`restartRDS_NS_Pvt.CFcase`（用 `restartRDS.plt`/`.surf.plt`）、`wedgeFS_SpaceTimeRestart.CFcase`、`doubleEllipse*.START_NS/START_LTE_DEMIX`、`BluntBody2D/*.START`。
4. **交互参数**：`.inter` 文件 + `InteractiveParamReader.FileName/readRate`——随迭代扫掠来流（`naca0012.inter`）、工况（ICP `.inter`）、网格移动（`gnoffoFRP9.inter`）。
5. **网格转换**：`convertFrom = THOR2CFmesh/Gambit2CFmesh/Gmsh2CFmesh/CGNS2CFmesh` 等 + 对应 `*.SP/.thor/*.neu/*.msh/*.dpl` 源文件——仓库所有第三方网格算例均按此模式工作（`CFmeshFileReader` 装载时即时转换）。
6. **对照链**：残差目标看文件头 `### Residual`；物理量对照看 7.3–7.8 各档案"预期结果"；结果复现差异排查按第 0.3.7 节三关键词。
